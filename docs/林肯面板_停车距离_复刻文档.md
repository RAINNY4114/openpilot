# 林肯面板：停车距离（Standstill Stop Distance）复刻文档

目标：不读源码即可 1:1 实现“停车距离”功能与 UI。

## 1. 必须修改/新增的文件清单
- common/params_keys.h
- selfdrive/ui/layouts/settings/lincoln.py
- selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py

## 2. 参数定义（common/params_keys.h）
- dp_lincoln_stop_distance_m：PERSISTENT INT，默认 "4"
  - 注释：最终刹停/红灯跟停期望静止车距（米）

## 3. 面板 UI（selfdrive/ui/layouts/settings/lincoln.py）
- 分组标题："### Following & Stopping ###"
- Spin："Stop distance (standstill)"
  - description："Target gap to the lead vehicle when coming to a stop (stop-and-go / red lights). Lower = closer; higher = more buffer."
  - initial_value：dp_lincoln_stop_distance_m（默认 4）
  - min=3, max=8, step=1, suffix=" m"
  - callback：Params.put("dp_lincoln_stop_distance_m", int(val))

## 4. 运行时逻辑（selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py）
### 4.1 常量
- STOP_DISTANCE = 6.0

### 4.2 仅 Ford/Lincoln 启用
- _is_ford_platform(): CP.brand == "ford" 时才启用参数读取与修正。

### 4.3 参数刷新
- _update_lincoln_params(): 每 1.0s 刷新 dp_lincoln_stop_distance_m
- 读取失败时保留上一次值（默认 4.0）

### 4.4 停车距离偏移计算
- _lincoln_stop_gap_shift(v_ego):
  - stop_gap_shift = STOP_DISTANCE - stop_distance_m
  - v_ego ≤ 5 m/s：100% 生效
  - v_ego ≥ 10 m/s：线性衰减到 0
  - 只在 is_ford_platform 为 True 时使用

### 4.5 MPC 中的应用
- update() 中：
  - lead_0_obstacle / lead_1_obstacle 先按原逻辑计算
  - 若对应 lead.status=True，则对 lead_xv 加 stop_gap_shift
  - 无 lead 时不应用偏移

## 5. 复刻步骤
1. common/params_keys.h 注册 dp_lincoln_stop_distance_m（默认 4）。
2. lincoln.py 添加 Spin 控件（范围 3–8）。
3. long_mpc.py 按上述逻辑读取参数并施加 stop_gap_shift。

## 6. 验证要点
- 开启时，低速跟停距离随设置变化。
- 车速提高后偏移逐步消失。
- 非 Ford/Lincoln 平台不生效。
