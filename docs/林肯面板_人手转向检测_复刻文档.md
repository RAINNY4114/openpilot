# 林肯面板：人手转向检测（Human Turn Detection）复刻文档
## 0. 功能定义
- 当驾驶员大角度+较大扭矩主动转向时，暂时暂停横向控制；松手后平滑恢复。

## 1. 必须涉及的文件清单
- `common/params_keys.h`
- `selfdrive/ui/layouts/settings/lincoln.py`
- `dragonpilot/selfdrive/controls/lib/human_turn_detection.py`
- `selfdrive/controls/controlsd.py`

## 2. 参数（`common/params_keys.h`）
- `dp_htd_enabled`：PERSISTENT BOOL，默认 `1`
- `dp_htd_turn_angle_threshold`：PERSISTENT INT，默认 `90`
- `dp_htd_turn_angle_release_deg`：PERSISTENT FLOAT，默认 `8.0`
- `dp_htd_torque_start_nm`：PERSISTENT FLOAT，默认 `1.2`
- `dp_htd_torque_release_nm`：PERSISTENT FLOAT，默认 `0.6`
- `dp_htd_recovery_delay`：PERSISTENT FLOAT，默认 `1.0`

## 3. Lincoln 面板 UI（`selfdrive/ui/layouts/settings/lincoln.py`）
- Toggle：`Enable Human Turn Detection` → `dp_htd_enabled`
- Spin：`Trigger angle` → `dp_htd_turn_angle_threshold`（min=30, max=120, step=1）
- 其余参数为隐藏参数（不在 UI 暴露）。

## 4. 状态机（`dragonpilot/selfdrive/controls/lib/human_turn_detection.py`）
### 4.1 状态
- `INACTIVE` / `MANUAL_TURN` / `RAMPING`

### 4.2 触发条件（INACTIVE → MANUAL_TURN）
- `abs(steeringTorque) >= dp_htd_torque_start_nm`
- `abs(steeringAngleDeg) >= dp_htd_turn_angle_threshold`

### 4.3 释放条件（MANUAL_TURN → RAMPING）
- `abs(steeringTorque) <= dp_htd_torque_release_nm`
- `abs(steeringAngleDeg) <= dp_htd_turn_angle_release_deg`

### 4.4 恢复条件（RAMPING → INACTIVE）
- `time_since_state_change >= dp_htd_recovery_delay`
- 若期间再次触发 → 回到 MANUAL_TURN

### 4.5 门槛
- `v_ego < 0.1 m/s` 或 `lat_active == False` → 直接允许控制（强制 INACTIVE）。

### 4.6 参数刷新与日志
- 参数刷新：`PARAM_REFRESH_SEC = 2.0`
- 日志：`/data/media/0/realdata/lincoln_debug.log`

## 5. 控制接入（`selfdrive/controls/controlsd.py`）
- 初始化：`self.htd = HumanTurnDetection()`
- 每帧：
  - `htd_allowed, htd_state = self.htd.update(...)`
  - `lat_active = lat_active and htd_allowed`

## 6. 复刻步骤
1. 注册全部 HTD 参数。
2. 面板加入开关与触发角度设置。
3. 实现 HTD 状态机和参数读取。
4. controlsd 中将 HTD 结果串入 `lat_active`。

## 7. 验证清单
- 大角度+扭矩时横向控制暂停。
- 松手后延时恢复。
- 低速或 lat_active=False 时不触发。
