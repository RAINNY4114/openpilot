## 1. 车道线（Lane Lines）

### 1.1 定义
- 共4条车道线：索引 0, 1, 2, 3
- 索引1和2：内侧车道线（当前车道的左右边界）
- 索引0和3：外侧车道线（相邻车道的边界）

### 1.2 宽度计算（Lines 352-356）

```python
for i, lane_line in enumerate(self._lane_lines):
    base = 0.055 if i in (1, 2) else 0.050
    line_width = base + 0.015 * self._lane_line_probs[i]
    lane_line.projected_points = self._map_line_to_polygon(
        lane_line.raw_points, line_width, 0.0, max_idx, max_distance
    )
```

**宽度参数：**

| 车道线 | 索引 | 基础宽度 | 置信度加成 | 最小宽度 | 最大宽度 |
|--------|------|---------|-----------|---------|---------|
| 内侧左 | 1 | 0.055 | +0.015 × prob | 0.055 | 0.070 |
| 内侧右 | 2 | 0.055 | +0.015 × prob | 0.055 | 0.070 |
| 外侧左 | 0 | 0.050 | +0.015 × prob | 0.050 | 0.065 |
| 外侧右 | 3 | 0.050 | +0.015 × prob | 0.050 | 0.065 |

**说明：**
- `prob` 是车道线置信度（0-1）
- 置信度越高，线条越粗
- 内侧线比外侧线粗 5%

### 3.3 多边形生成逻辑（Lines 676-677, 727）

```python
# 生成左右边界点
```

**宽度参数：**

| 元素 | 总宽度 | 左边界偏移 | 右边界偏移 | 说明 |
|------|--------|-----------|-----------|------|
| 路径带 | 0.9 | -0.45 | +0.45 | 固定宽度，最粗的元素 |
| 路径带左边界线 | - | -0.45 | - | 从中心线向左偏移 |

**说明：**
- 路径带是一个**填充的多边形**，不是单条线
- 多边形有**两条边界线**：左边界和右边界
- 每条边界线距离中心线 **0.45**（总宽度的一半）
- 用户在HUD上看到的"两条绿色线条"就是这两条边界线

## 5. 视觉层次设计

**从粗到细的视觉层次：**

1. **路径带（0.9）** - 最粗，最重要
   - 绿色，表示规划路径
   - 驾驶员主要关注点

2. **路沿线（0.08）** - 次粗
   - 橙色/黄色，警示作用
   - 表示道路边界

3. **内侧车道线（0.055-0.070）** - 中等
   - 白色/黄色
   - 当前车道边界，重要性高

4. **外侧车道线（0.050-0.065）** - 最细
   - 白色/黄色
   - 相邻车道边界，重要性低

## 6. 宽度单位说明

**这些宽度值是归一化坐标：**
- 不是像素值，也不是米
- 是相对于视角变换后的坐标系
- 实际屏幕像素取决于：
  - 屏幕分辨率
  - 视角变换矩阵
  - 距离远近（透视效果）

**近处vs远处：**
- 近处：线条在屏幕上更粗（透视效果）
- 远处：线条在屏幕上更细（透视效果）
- 但归一化宽度保持不变

## 7. 动态宽度特性

### 7.1 车道线动态宽度
- 基础宽度固定
- 根据置信度动态调整
- 置信度高 → 线条粗 → 视觉上更明显

### 7.2 路径带和路沿线
- 宽度固定，不随置信度变化
- 保持一致的视觉效果
