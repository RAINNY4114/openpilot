# 林肯面板：盲区语音提示（Blindspot Voice Alerts）复刻文档
## 0. 功能定义
- 车辆左右盲区触发时播放语音提示（左/右）。
- 仅语音提示，不影响控制。

## 1. 必须涉及的文件清单
- `common/params_keys.h`
- `selfdrive/ui/layouts/settings/lincoln.py`
- `selfdrive/ui/soundd.py`
- `selfdrive/assets/sounds/left.wav`
- `selfdrive/assets/sounds/right.wav`

## 2. 参数（`common/params_keys.h`）
- `dp_lincoln_bsm_voice_enabled`：PERSISTENT BOOL，默认 `0`
- `dp_lincoln_bsm_voice_interval_sec`：PERSISTENT INT，默认 `3`
- `dp_lincoln_bsm_voice_volume_pct`：PERSISTENT INT，默认 `100`

## 3. Lincoln 面板 UI（`selfdrive/ui/layouts/settings/lincoln.py`）
- Toggle：`Blindspot Voice Alert` → `dp_lincoln_bsm_voice_enabled`
- Spin：`Voice repeat interval` → `dp_lincoln_bsm_voice_interval_sec`（min=1, max=10, step=1）
- Spin：`Voice volume` → `dp_lincoln_bsm_voice_volume_pct`（min=20, max=100, step=5）

## 4. 运行逻辑（`selfdrive/ui/soundd.py`）
### 4.1 参数刷新
- 每 1s 刷新一次参数（`_refresh_dp_voice_params`）。
- `dp_lincoln_bsm_voice_interval_sec` 强制 `>= 1.0`；`dp_lincoln_bsm_voice_volume_pct` 线性缩放并裁剪到 0–1。

### 4.2 触发条件
- `carState.leftBlindspot` / `rightBlindspot` 从 False→True 上升沿触发。
- `dp_lincoln_bsm_voice_enabled == True`。
- 冷却：`dp_lincoln_bsm_voice_interval_sec`（秒）。
- 若有系统主提示音播放中（`current_alert != none`）或当前盲区语音正在播放，则不触发。

### 4.3 音频加载
- 优先文件：`left.wav` / `right.wav`。
- 兼容回退：`left-side.wav` / `right-side.wav`。
- 文件缺失时仅记录 warning，不崩溃。

### 4.4 音量
- `dp_lincoln_bsm_voice_volume_pct / 100` → 线性缩放。

## 5. 依赖
- 车辆必须支持 BSM 传感器，否则 `leftBlindspot/rightBlindspot` 恒为 False。

## 6. 复刻步骤
1. 注册 3 个参数。
2. 面板添加 1 个开关 + 2 个调节项。
3. soundd 加载语音文件并监听 blindspot 状态。

## 7. 验证清单
- 打开开关后进入盲区立即播报。
- 冷却时间生效，短时间内不重复播报。
- 关闭开关后不再触发。
