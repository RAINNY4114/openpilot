# 地图复刻文档（FP 1:1）

> 目标：完整描述地图链路与代码路径，确保可按文档 1:1 复刻。

## 1. mapd 运行策略与二进制路径
**文件**：`system/manager/process_config.py`
- `mapd` 常驻运行（`always_run=True`）

**文件**：`selfdrive/mapd/mapd.py`
- mapd 二进制路径：`/data/media/0/osm/mapd`
- 版本文件：`/data/media/0/osm/mapd_version`
- 启动方式：`mapd.py` 负责**下载/更新**并拉起 `/data/media/0/osm/mapd`
- 下载来源常量：`GITHUB_VERSION_URL` / `GITLAB_VERSION_URL` / `MAPD_DOWNLOAD_URLS`
 - 说明：**无离线地图时 mapd 仍常驻，但不会产生有效 `MapTargetVelocities`**

## 2. 离线地图数据
**文件**：`selfdrive/ui/layouts/settings/osm_maps.py`  
**入口**：`selfdrive/ui/layouts/settings/settings.py`
- 离线地图目录：`/data/media/0/osm/offline`
- 面板参数：`MapsSelected` / `LastMapsUpdate` / `MapsSize` 等（用于选择与下载）

## 3. mapd 输出（/dev/shm/params）
**文件**：`common/params_keys.h`
- `MapTargetVelocities`（STRING）
- `LastGPSPosition`（STRING）
- `GPSQualityOK`（BOOL）
- `RoadName`（STRING，**可选**：若 mapd 提供则用于 HUD 道路名）

**文件**：`selfdrive/mapd/mapd.py`
- GPS 写线程（2 Hz）写入：  
  - `LastGPSPosition`：`latitude/longitude/bearing`  
  - `GPSQualityOK`：GPS 质量门控
  - 数据源：`gpsLocationExternal` 优先，失败回退 `gpsLocation`

**文件**：`selfdrive/controls/lib/longitudinal_planner.py`
- 也会写入 `LastGPSPosition`（来源 `liveLocationKalman`）

**文件**：`/data/media/0/osm/mapd`（二进制）
- 负责写入 `MapTargetVelocities`
- 使用离线地图 `/data/media/0/osm/offline`

## 4. MapTargetVelocities 数据格式（FP 解析规则）
**文件**：`selfdrive/controls/lib/longitudinal_planner.py`
- 解析字段兼容：`latitude/longitude` 或 `lat/lon/lng`
- JSON 示例（示意）：
```json
[
  {"latitude": 31.2304, "longitude": 121.4737},
  {"lat": 31.2305, "lon": 121.4740},
  {"lat": 31.2307, "lng": 121.4745}
]
```

## 5. 地图弯道限速（与 FP 一致）
**文件**：`selfdrive/controls/lib/longitudinal_planner.py`
- 门控：`CurveSpeedControl=1` + `MapTurnControl=1` + `controlsState.enabled=1`
- 速度门槛：`v_ego > 5 m/s`
- 视觉前置：`MTSCCurvatureCheck=1` 时必须先检测到视觉曲率
- 目标速度：  
  `v = sqrt((TARGET_LAT_A * TurnAggressiveness) / (curvature * CurveSensitivity))`
 - 读取 `MapTargetVelocities`：`Params("/dev/shm/params")`

## 6. HUD / UI 关联
**文件**：`selfdrive/ui/layouts/settings/lincoln.py`
- 「曲线检测方法」三选一：**基于地图 / 视觉 / 地图+视觉**
- 只有离线地图已下载时，地图相关选项可用

**文件**：`selfdrive/ui/onroad/hud_renderer.py`
- HUD 弯道提示门控：`CurveSpeedControl=1` 且 `ShowCSCStatus=1`

**文件**：`selfdrive/ui/onroad/augmented_road_view.py`
- `Road` 字段优先读 `RoadName`，无则回退经纬度
