## 离线地图（OSM）功能「完整复刻」文档

> 目标：在其它分支/设备上 1:1 复刻“离线地图下载 + mapd 后台服务 + 定时更新 + 实时巡航（地图弯道预限速）+ HUD 道路名/位置显示”整套功能。
>
> 本文按 **参数 → 进程 → UI → 数据流 → 使用与排错** 的顺序列出涉及的代码与逻辑；逐项移植即可复刻。

---

### 0. 功能概览（你得到什么）

1. **离线地图下载面板**：设置 → `离线地图`（`Offline Maps`）提供
   - 地图更新频率（手动/每周/每月）
   - 地图源选择（国家/美国州）
   - 一键下载/取消、进度/耗时/剩余时间、存储占用
   - 删除已下载地图、重置下载器（清空并重启）
2. **mapd 后台服务**：
   - 自动下载/更新 `mapd` 二进制（来自 FrogPilot/开源镜像的公开资源链接）
   - 在下载时写入进度 `OSMDownloadProgress`
   - 下载离线数据到 `/data/media/0/osm/offline`
   - 根据 GPS 位置匹配道路名写入 `RoadName`
   - 输出地图弯道目标速度点集 `MapTargetVelocities`（供实时巡航限速）
3. **maps_updater 定时更新**：
   - 根据 `PreferredSchedule`（每周/每月）在 offroad 自动触发下载，并写入 `LastMapsUpdate`
4. **实时巡航模式（Lincoln/Ford）**：
   - 开关 `dp_lincoln_osm_realtime_cruise` 开启后，驾驶中 mapd 常驻运行
   - 纵向规划在可用时优先使用 `MapTargetVelocities` 做“地图弯道预限速”（对视觉弯道限速形成补充/优先级）
5. **HUD 底部道路位置**：
   - 优先显示 `RoadName`（来自 mapd）
   - 无 mapd/无匹配时回退显示 `lat,lon`

### 1. 参数声明（Params Keys）

**文件**：`common/params_keys.h`

需要确保以下键存在（本项目已包含；移植时照抄即可）：

```cpp
{"dp_lincoln_osm_realtime_cruise", {PERSISTENT, BOOL, "0"}},
{"MapsSelected", {PERSISTENT, STRING}},
{"LastMapsUpdate", {PERSISTENT, STRING}},
{"PreferredSchedule", {PERSISTENT, INT, "0"}},
{"OSMDownloadBounds", {PERSISTENT, STRING}},
{"OSMDownloadLocations", {PERSISTENT, STRING}},
{"OSMDownloadProgress", {CLEAR_ON_MANAGER_START, STRING}},
{"RoadName", {CLEAR_ON_MANAGER_START, STRING}},
{"MapTargetVelocities", {PERSISTENT, STRING}},
{"LastGPSPosition", {PERSISTENT, STRING}},
```

**语义约定（关键点）**：

- `MapsSelected`：用户选择的地图源（JSON，结构见 `osm_maps.py`）。
- `PreferredSchedule`：地图更新频率索引（0=手动，1=每周，2=每月）。
- `OSMDownloadLocations`：**下载触发器**（本实现将其写入 `/dev/shm/params`，用于触发 mapd 下载；可理解为“临时任务”）。
- `OSMDownloadProgress`：下载进度（由 mapd 写入；UI 读取并显示）。
- `LastMapsUpdate`：最近一次下载/更新完成的日期字符串（UI 显示；`maps_updater`/UI 会写入）。
- `LastGPSPosition`：mapd 启动器写入的 GPS（JSON：`latitude/longitude/bearing`）。
- `RoadName`：mapd 输出的“当前道路名称/编号”（HUD 优先显示）。
- `MapTargetVelocities`：mapd 输出的“前方若干点的目标速度列表”（供纵向规划做地图弯道预限速）。

### 2. 进程管理（manager 启停逻辑）

**文件**：`system/manager/process_config.py`

#### 2.1 `mapd` 的启用条件

```python
def mapd(started: bool, params: Params, CP: car.CarParams) -> bool:
  # Run mapd when:
  # - user requested an offline maps download, or
  # - onroad realtime cruise mode is enabled
  try:
    params_memory = Params("/dev/shm/params")
    if params_memory.get("OSMDownloadLocations"):
      return True
  except Exception:
    pass
  return started and params.get_bool("dp_lincoln_osm_realtime_cruise")
```

含义：

- **离线下载**：只要 `/dev/shm/params` 里存在 `OSMDownloadLocations`，就强制启动 `mapd`（哪怕 offroad）。
- **实时巡航**：onroad 且 `dp_lincoln_osm_realtime_cruise=1` 时启动 `mapd` 常驻。

#### 2.2 进程注册

```python
PythonProcess("maps_updater", "selfdrive.mapd.maps_updater", always_run, enabled=not PC),
PythonProcess("mapd", "selfdrive.mapd.mapd", mapd, enabled=not PC),
```

注意：

- `enabled=not PC`：PC 环境不会真正运行 mapd/maps_updater（UI 可以显示，但功能在 PC 上不可验证）。

### 3. mapd 启动器（负责下载/启动 mapd 二进制 + 写 GPS）

**文件**：`selfdrive/mapd/mapd.py`

它是一个 Python “守护启动器”，职责是：

1. **下载/更新 mapd 二进制**
   - 读取版本文件：`/data/media/0/osm/mapd_version`
   - 定期拉取最新版本指针（每小时一次）：
     - `https://github.com/FrogAi/FrogPilot-Resources/raw/Versions/mapd_version_v2.json`
     - `https://gitlab.com/FrogAi/FrogPilot-Resources/-/raw/Versions/mapd_version_v2.json`
   - 依次尝试下载二进制（失败自动切换镜像）：
     - `https://github.com/pfeiferj/openpilot-mapd/releases/download/{version}/mapd`
     - `https://gitlab.com/FrogAi/FrogPilot-Resources/-/raw/Mapd/{version}`
     - `https://github.com/pfeiferj/mapd/releases/download/{version}/mapd`
   - 存放路径：`/data/media/0/osm/mapd`（下载完成后赋可执行权限）
2. **写入 GPS 位置给二进制使用**
   - 订阅 `gpsLocationExternal`（2Hz 足够）
   - 写入 `/dev/shm/params`：`LastGPSPosition={"latitude":..,"longitude":..,"bearing":..}`
3. **启动并守护 mapd**
   - `subprocess.Popen([MAPD_PATH])` 运行二进制
   - 退出后 1s 再拉起（持续守护）

> 说明：离线地图下载、道路匹配、弯道速度点集计算等核心逻辑在 `mapd` 二进制内部完成；本仓库只负责触发与展示/消费其输出。

---

### 4. maps_updater（离线定时更新触发器）

**文件**：`selfdrive/mapd/maps_updater.py`

核心逻辑：

- 仅在 **offroad** 执行（`IsOnroad` 为真则直接长睡眠）
- 读取 `PreferredSchedule`
  - `0`：手动（不自动更新）
  - `1`：每周（日历周日触发）
  - `2`：每月（每月 1 日触发）
- 满足触发条件时写入 `/dev/shm/params`：`OSMDownloadLocations`（与 UI 的手动下载同一触发路径）
- 等待 `OSMDownloadProgress` 出现并结束，完成后：
  - 清理 `OSMDownloadLocations`
  - 若离线文件存在则写入 `LastMapsUpdate`（当天日期字符串）

### 5. 设置面板（离线地图下载界面）

涉及文件：

- 面板入口：`selfdrive/ui/layouts/settings/settings.py`
  - `PanelType.OSM_MAPS` + `PanelInfo(tr_noop("Offline Maps"), OSMMapsLayout())`
- 面板实现：`selfdrive/ui/layouts/settings/osm_maps.py`

#### 5.1 UI 结构（与状态联动）

`OSMMapsLayout` 主要控件：

- `Automatically Update Maps`：三段按钮 `Manually/Weekly/Monthly` → 写入 `PreferredSchedule`
- `Download Maps`：`DOWNLOAD` / `CANCEL`（下载时变为取消）
  - 仅在 **在线 + 驻车(offroad) + 已选择地图源** 时可点击
- `Last Updated`：显示 `LastMapsUpdate`（下载中隐藏）
- `Map Sources`：进入选择页（下载中禁用）
  - `COUNTRIES`：按洲分组选择国家（含 `CN`）
  - `STATES`：按美国区域选择州（Midwest/Northeast/South/West/Territories）
- 下载中显示：
  - `Progress`：读取 `OSMDownloadProgress`（文件数进度）
  - `Time Elapsed` / `Time Remaining`：基于下载开始时间 + 进度估算
- 维护项：
  - `Remove Maps`：删除 `/data/media/0/osm/offline`
  - `Reset Downloader`：删除 `/data/media/0/osm` 并写 `DoReboot=1`
  - `Storage Used`：扫描 `/data/media/0/osm/offline` 估算占用（缓存 1s）
- `Realtime cruise mode`：开关 `dp_lincoln_osm_realtime_cruise`
  - 仅当检测到离线地图文件存在时才允许开启

#### 5.2 China 选择是否需要“地区”？

- 国家列表里 **选择 `CN` 即可**（不需要再选择省/市级“地区”）。
- “州（STATES）”只针对美国；其它国家（含中国）都在 `COUNTRIES` 页。

### 6. 下载/取消/完成：关键数据流（参数状态机）

#### 6.1 手动下载（UI 触发）

**触发点**：`OSMMapsLayout._start_download()`

1. UI 写入（内存 Params）：`OSMDownloadLocations = json.dumps(MapsSelected)`
2. manager 发现 `OSMDownloadLocations` 后启动 `mapd`（见 `process_config.py`）
3. `mapd` 二进制开始下载，写入：
   - `OSMDownloadProgress`（进度 JSON，至少包含 `total_files/downloaded_files`）
4. UI 轮询展示：进度/耗时/剩余时间，并保持屏幕常亮（`device.reset_interactive_timeout(300)`）
5. 下载完成后：
   - mapd 可能会清理 `OSMDownloadLocations`/`OSMDownloadProgress`
   - 若某些 mapd 版本未清理：UI 在检测到 `done>=total` 且离线文件存在时，会自动清理并写入 `LastMapsUpdate`

#### 6.2 取消下载

**触发点**：`OSMMapsLayout._cancel_download()`

- 清理 `OSMDownloadProgress` 与 `OSMDownloadLocations`
- `pkill mapd`（中止正在运行的 mapd 二进制）

#### 6.3 删除/重置

- `Remove Maps`：删除 `/data/media/0/osm/offline`（不重启）
- `Reset Downloader`：删除 `/data/media/0/osm`（包含 mapd、离线文件与缓存）并写 `DoReboot=1`

### 8. 实时巡航（地图弯道预限速）如何接入纵向控制

涉及文件：

- 入口：`selfdrive/controls/plannerd.py`
  - 将 `dp_lincoln_osm_realtime_cruise` 传入 `LongitudinalPlanner.update(..., lincoln_osm_realtime_cruise=...)`
- 实现：`selfdrive/controls/lib/longitudinal_planner.py`

#### 8.1 工作条件

满足以下条件才会尝试启用地图弯道限速：

- `dp_lincoln_osm_realtime_cruise = 1`
- `selfdriveState.enabled = True`
- `v_cruise > 0`
- `gpsLocationExternal.hasFix = True`
- `MapTargetVelocities` 有有效数据（由 mapd 输出）

#### 8.2 数据输入：`MapTargetVelocities`

`LongitudinalPlanner` 会优先从 `/dev/shm/params` 读取 `MapTargetVelocities`，取不到再读持久 Params：

```python
raw = self._params_memory.get("MapTargetVelocities") or self._params.get("MapTargetVelocities")
parsed = json.loads(raw)  # list[dict]
```

列表元素预期包含：

- `latitude` / `longitude`
- `velocity`（目标速度，单位 m/s）

#### 8.3 速度目标计算（核心思路）

`_map_turn_target_speed()` 会：

1. 找到离当前 GPS 最近的点作为起始索引
2. 向前遍历后续点，筛选出 `0 < tv <= v_ego` 的目标速度
3. 根据“可实现减速度距离”判断该点是否需要提前降到 `tv`
   - 使用固定目标 jerk/accel（类似 FrogPilot/CP 的策略）：
     - `_MAP_TARGET_JERK = -0.6 m/s^3`
     - `_MAP_TARGET_ACCEL = -1.2 m/s^2`
4. 返回所有“需要降速”的点里 **最小 tv** 作为 `v_map_target`

补充（本仓库的“高速体验优化”点）：
- `_map_turn_target_speed()` 还包含一个 `preview cap`（预限速上限），用于在“暂时不需要立刻减速”时先收紧 `v_cruise` 上限，减少进入弯道前的抖动与分段降速。
- 为避免高速在轻微弯道/噪声点集下出现“提前猛砍到 70/80”的体验，本仓库将 `preview cap` 改为 **距离物理约束的软上限**：
  - 从“extended 预览窗口”（约 20s/120~800m）内取最低地图目标速度 `v_min` 及其距离 `d_min`
  - 计算软上限 `v_cap = sqrt(v_min^2 + 2*|a_preview|*d_use)`（`d_use` 含 1s 偏移），只有当 `v_cap < v_cruise` 时才会开始逐步收紧
  - `v_cap` 依然做“快收紧、慢放松”滤波，减少抖动与分段下压体感
  - 代码位置：`selfdrive/controls/lib/longitudinal_planner.py` → `_map_turn_target_speed()`

#### 8.4 生效位置（优先级）

在 `update()` 内，当 `map_turn_limit_active` 为真时会执行：

```python
v_cruise = min(v_cruise, v_map_target)
```

这意味着：地图弯道目标速度会直接压低纵向巡航上限（对视觉弯道限速形成“优先约束/互补”）。

### 9. HUD 道路名/位置显示（RoadName → HUD）

**文件**：`selfdrive/ui/onroad/augmented_road_view.py`

`_get_road_location_text()` 逻辑：

1. 优先从 Params（先 `/dev/shm/params` 再持久 Params）读取 `RoadName`
2. 若为空，则回退到 `gpsLocationExternal/gpsLocation` 经纬度，格式为 `lat,lon`（5 位小数）
3. 内部带 0.5s 缓存；`RoadName` 超长会截断（22 字符，尾部 `…`）

这使得：离线地图下载完成并且 mapd 正常运行时，HUD 底部可显示当前道路名称/编号；无地图时不影响基本显示。

### 11. 常见问题与排查（建议写进你的路测/调试流程）

1. **下载按钮不可点**
   - 未驻车/在行驶中（需要 offroad）
   - `MapsSelected` 为空
   - 没网（`deviceState.networkType=none`）
2. **下载中一直“Calculating...”**
   - mapd 二进制未启动/崩溃
   - `OSMDownloadProgress` 没有被写入（检查 `Params`）
3. **mapd 频繁退出**
   - 优先用面板 `Reset Downloader` 清空 `/data/media/0/osm` 并重启
   - 再观察是否能重新下载 `mapd` 与离线文件
4. **实时巡航开关无法打开**
   - 面板逻辑要求“离线地图文件存在”才允许开启（先下载）
5. **HUD 没有道路名**
   - `RoadName` 为空：可能当前位置无法匹配、GPS 无 fix、mapd 未运行
   - 回退显示经纬度属于正常行为（不影响驾驶）
6. **高速弯道不“地图融合”/不减速**
   - 确认 `dp_lincoln_osm_realtime_cruise=1` 且上路 `selfdriveState.enabled=True`
   - 确认 GPS 有 fix（`gpsLocationExternal/gpsLocation.hasFix=True`），且 `LastGPSPosition` 在更新
   - 确认 `MapTargetVelocities` 非空（通常在 `/dev/shm/params`），为空则纵向不会触发地图限速
   - 若 Ford 处于原车 ACC（`openpilotLongitudinalControl=False`）：实际减速由原车 ACC 执行；本功能主要通过“收紧 v_cruise/设定车速”来让原车 ACC 降速，效果取决于原车对设定速度变化的响应策略
