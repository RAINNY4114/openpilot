# 林肯面板：曲线速度控制（Curve Speed Control）复刻文档（当前分支实况）

更新时间：2026-03-07

## 0. 功能边界（先看这个）
- 目标：在弯道前自动降速，并在 HUD 上显示弯道目标速度/提示。
- 影响范围：`longitudinal_planner` 纵向目标速度轨迹 + HUD 信息显示 + 路径红色提示。
- 不直接控制：转向控制器本身（不改横向控制律）。

## 2. 参数与默认值（已按当前代码核对）
来源：`common/params_keys.h`

- `CurveSpeedControl`：`BOOL`，默认 `1`
- `CurveSensitivity`：`INT`，默认 `100`（百分比，100 => 1.0）
- `TurnAggressiveness`：`INT`，默认 `100`（百分比，100 => 1.0）
- `MapTurnControl`：`BOOL`，默认 `1`
- `VisionTurnControl`：`BOOL`，默认 `1`
- `ShowCSCStatus`：`BOOL`，默认 `1`（HUD 显示门控，不在 Lincoln 面板暴露）

说明：
- 当前默认值为 `100`。
- 手动调到 `200` 会让目标速度更保守（更低）。

## 3. 面板行为（`lincoln.py`）
### 3.1 基本项
- `Curve Speed Control`：总开关。
- `Curve Detection Method`：`Map Based / Vision / Map + Vision`。
- `Curve Detection Sensitivity`：`50~200`，步进 `5`，默认显示回退值 `100`。
- `Curve Speed Aggressiveness`：`50~200`，步进 `5`，默认显示回退值 `100`。

### 3.2 离线地图缺失时的强制行为
- 检查路径：`/data/media/0/osm/offline`。
- 若无离线地图：选择 `Map Based` 或 `Map + Vision` 时，会弹提示并强制切到 `Vision`。
- `show_event()` 也会调用 `_normalize_curve_method()` 做参数纠偏，避免无效组合。

## 4. plannerd 入口
来源：`selfdrive/controls/plannerd.py`

- 每次模型帧更新时读取：`Params.get_bool("CurveSpeedControl")`
- 调用：`longitudinal_planner.update(..., curve_speed_control=...)`

## 5. 纵向核心逻辑（`longitudinal_planner.py`）

### 5.1 当前关键常量
- `_FP_TARGET_LAT_A = 2.0`
- `_FP_CURVE_SENSITIVITY = 1.0`（默认回退值，已对应 100%）
- `_FP_CURVE_DETECT_LAT_A = 1.0`
- `_FP_TURN_AGGRESSIVENESS = 1.0`
- `_FP_CRUISING_SPEED = 5.0 m/s`

Taco 轨迹限速相关：
- `_FP_TACO_LAT_BP = [5, 10, 20]`
- `_FP_TACO_LAT_VALS = [1.5, 2.0, 3.0]`
- `_FP_TACO_MARGIN = 2.0`
- `_FP_TACO_CLIP_EPS = 0.05`

来源抖动抑制：
- `_FP_CURVE_SRC_HYST = 0.25`
- `_FP_CURVE_SRC_MIN_HOLD_S = 0.6`

### 5.2 总门控
- 若 `CP.openpilotLongitudinalControl == False`，会把 `curve_speed_control` 强制关掉。
- `controls_enabled` 取 `controlsState.enabled`（无则回退 `selfdriveState.enabled`）。

### 5.3 参数读取频率
- 每 1 秒缓存刷新一次（`_fp_curve_config()`）。

### 5.4 视觉曲率检测
- 曲率估计：`max(|orientationRate.z * velocity.x|) / max(v_ego,1)^2`
- 检测条件：
  - `lat_accel_pred > 1.0`
  - `v_ego > 5.0 m/s`
  - 非转向灯状态

重要：
- `CurveSensitivity` 不改变这个“检测阈值 1.0”，它只影响目标速度计算（见 5.6）。

### 5.5 地图曲率与前瞻
- `MapTargetVelocities` 从 `/dev/shm/params` 读取（JSON list，带 raw 缓存）。
- GPS 取 `liveLocationKalman`（有效时写 `LastGPSPosition`）。
- 地图前瞻距离：`lookahead_dist = ModelConstants.T_IDXS[-1] * v_ego`（约 10 秒时域换算距离）。
- 当前实现是按“车到各点距离”累计（不是点到点段长累计），这是现有行为。

### 5.6 目标速度计算
Map：
- 条件：`curve_speed_control && map_enabled && controls_enabled && v_ego > 5`
- 公式：
  `map_speed = sqrt((_FP_TARGET_LAT_A * turn_aggressiveness) / (map_curv * curve_sensitivity))`

Vision：
- 条件：`curve_speed_control && vision_enabled && controls_enabled && road_curvature_detected && v_ego > 5`
- 公式：
  `vision_speed = sqrt((_FP_TARGET_LAT_A * turn_aggressiveness) / (abs(road_curvature) * curve_sensitivity))`

结论：
- `curve_sensitivity` 越大，目标速度越低（更保守）。
- `CurveSensitivity` 从 `100%` 调到 `200%` 时，同曲率下目标速度约变为 `1/sqrt(2)` 倍。

### 5.7 Taco 轨迹裁剪（已在当前分支启用）
- 在 `parse_model()` 中直接裁剪模型速度轨迹 `v[]`，不是只改 `v_cruise`。
- 裁剪条件需满足 `reduction > _FP_TACO_CLIP_EPS`。
- 这会让 MPC 更早看到低速轨迹，提升弯前减速一致性。

### 5.8 最终来源选择（已非“仅 map/vision 二选一”）
候选来源：
- Map 限速（source=2）
- Vision 限速（source=1）
- Taco HUD 候选（归类为 source=1）

然后做：
- 取最小目标速度优先
- 近似目标时做来源滞回（`_FP_CURVE_SRC_HYST`）
- 来源切换最短保持时间（`_FP_CURVE_SRC_MIN_HOLD_S`）

发布字段：
- `longitudinalPlan.curveSpeedSource`
- `longitudinalPlan.vTargetDEPRECATED`

## 6. HUD 显示逻辑（`hud_renderer.py`）
显示前提：
- `CurveSpeedControl == True`
- `ShowCSCStatus == True`
- 巡航已设定
- `v_ego >= 1 m/s`
- `modelV2` 为 onroad 后新帧
- 模型数组长度一致
- `curveSpeedSource in (1,2)` 且 `curve_target < set_speed`

目标速度来源：
- 先用 `vTargetDEPRECATED`，无效时回退 `min(longitudinalPlan.speeds)`。

目标距离：
- 在规划速度时域上积分得到“到目标速度点”的距离估计。

图标方向：
- 用 `orientationRate.z / velocity.x` 判左右。
- 带死区和 0.25s 持有防抖。

## 7. 路径红色提示（`model_renderer.py`）
- 当 `curveSpeedSource in (1,2)`：红色强度基于 `v_ego` 与 `v_min(speeds)` 的速度落差。
- 当未限速：回退到模型预测横向加速度 `lat_accel_max` 做弱提示。
- 非 onroad、参数关闭、或 `longitudinalPlan` 非新帧时直接清零。

## 8. 地图进程与离线数据
- `mapd` 在 `process_config.py` 中设为常驻（`return True`）。
- `maps_updater` 常驻，按计划写 `OSMDownloadLocations` 触发下载。
- `mapd` 二进制路径：`/data/media/0/osm/mapd`
- 离线地图目录：`/data/media/0/osm/offline`

## 9. 今天已确认生效的改动（避免误导）
- 已删除 `MTSCCurvatureCheck`（`Curve Detection Failsafe`）参数与代码门控，Map 限速不再依赖视觉曲率确认。
- CSC 源选择包含 Taco 候选，并有滞回/最短保持，降低来源抖动。
- 轨迹裁剪 + HUD 同步逻辑已在同一条链路内工作。

### 9.1 `f64e4d2` 中的附带优化（非 CSC 核心，但当前分支仍生效）
- `opendbc_repo/opendbc/car/ford/interface.py`
  - `ret.steerLimitTimer` 从 `1.0` 调整为 `5.0`（提升转向饱和告警容忍时间）。
- `selfdrive/controls/controlsd.py`
  - road-edge 横向偏置改为更保守策略（提高置信门槛、减小偏置幅度、增加高速衰减、加大平滑时间常数），用于降低多弯道下横向干扰。

说明：
- `f64e4d2` 当时在 `selfdrived.py` 新增了 `steerSaturated` 诊断日志，但该日志后来已删除（因日志接口参数不兼容导致异常）；当前分支以“稳定运行优先”为准。
- `f64e4d2` 里 `model_renderer.py` 曾把 `road_edge_width` 改为 `0.05`，但当前代码为 `0.08`，以当前代码为准。

## 10. 已清理的旧误导点
- 旧文“默认启用 `Curve Detection Failsafe (MTSCCurvatureCheck)`”已过期：该功能已移除。
- 旧文“来源只可能 map/vision”不准确：当前还会纳入 Taco 视觉候选。
- 旧文“灵敏度提高=更早检测到弯道”不准确：检测阈值仍是固定 `1.0 m/s²`，灵敏度主要影响目标速度保守程度。

## 11. 验证清单（当前版本）
1. 关闭 `CurveSpeedControl`：HUD 弯道组件不显示，路径红提示清零。
2. Map/Vision/Map+Vision 切换：参数组合正确；无离线地图时强制回 Vision。
3. 弯道场景中 `curveSpeedSource` 有效变为 `1` 或 `2`。
4. `vTargetDEPRECATED` 与 HUD 显示目标速度一致。
5. `CurveSensitivity` 从 100 调到 200 后，同路段目标速度明显更低（更保守）。
