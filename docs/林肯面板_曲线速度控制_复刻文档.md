# 林肯面板：曲线速度控制（Curve Speed Control）复刻文档
## 0. 功能定义
- 目标：提前为弯道降速，来源可选“地图/视觉/融合”。
- 影响范围：纵向限速 + HUD 显示（弯道图标/目标速度/距离）+ 路径红色渐变提示。
- 不影响：方向控制本身（仅限速）。

## 1. 必须涉及的文件清单
- `common/params_keys.h`
- `selfdrive/ui/layouts/settings/lincoln.py`
- `selfdrive/controls/plannerd.py`
- `selfdrive/controls/lib/longitudinal_planner.py`
- `selfdrive/ui/onroad/hud_renderer.py`
- `selfdrive/ui/onroad/model_renderer.py`
- `system/manager/process_config.py`
- `selfdrive/mapd/mapd.py`
- `selfdrive/mapd/maps_updater.py`

## 2. 参数与默认值（`common/params_keys.h`）
- `CurveSpeedControl`：PERSISTENT BOOL，默认 `1`
- `CurveSensitivity`：PERSISTENT INT，默认 `100`（百分比，100=1.00x）
- `TurnAggressiveness`：PERSISTENT INT，默认 `100`（百分比，100=1.00x）
- `MapTurnControl`：PERSISTENT BOOL，默认 `1`
- `VisionTurnControl`：PERSISTENT BOOL，默认 `1`
- `MTSCCurvatureCheck`：PERSISTENT BOOL，默认 `1`
- `ShowCSCStatus`：PERSISTENT BOOL，默认 `1`（只用于 HUD 显示，不在面板暴露）

## 3. Lincoln 面板 UI（`selfdrive/ui/layouts/settings/lincoln.py`）
### 3.1 主开关
- Toggle：`Curve Speed Control` → `CurveSpeedControl`
- 描述：`Automatically slow down for upcoming curves using downloaded maps or the driving model.`

### 3.2 曲线检测方法（三态按钮）
- 组件：`multiple_button_item`
- 标题：`Curve Detection Method`
- 按钮：`Map Based` / `Vision` / `Map + Vision`
- 宽度：`button_width=255`
- 回调逻辑（`_on_curve_method_selected`）：
  - Map Based：`MapTurnControl=True`, `VisionTurnControl=False`
  - Vision：`MapTurnControl=False`, `VisionTurnControl=True`
  - Map + Vision：`MapTurnControl=True`, `VisionTurnControl=True`
- 离线地图缺失时强制回退：
  - `_has_offline_maps()` 仅检查 `/data/media/0/osm/offline` 是否存在文件。
  - 若无离线地图且选择 Map Based/Map + Vision → 弹窗提示并强制改为 Vision。
  - 提示文案：`The <b>Map Based</b> options are only available when some <b>Map Data</b> has been downloaded!`

### 3.3 Failsafe + 参数调节
- Toggle：`Curve Detection Failsafe` → `MTSCCurvatureCheck`
- Spin：`Curve Detection Sensitivity` → `CurveSensitivity`
  - min=50, max=200, step=5, suffix=" %"
- Spin：`Curve Speed Aggressiveness` → `TurnAggressiveness`
  - min=50, max=200, step=5, suffix=" %"

## 4. plannerd 入口（`selfdrive/controls/plannerd.py`）
- 每帧读取：`curve_speed_control_enabled() = Params.get_bool("CurveSpeedControl")`
- 调用：`longitudinal_planner.update(sm, dp_flags, curve_speed_control=curve_speed_control_enabled())`

## 5. 纵向规划核心逻辑（`selfdrive/controls/lib/longitudinal_planner.py`）
### 5.1 固定常量（保持一致）
- `_FP_TARGET_LAT_A = 2.0`
- `_FP_CURVE_SENSITIVITY = 1.0`
- `_FP_CURVE_DETECT_LAT_A = 1.0`
- `_FP_TURN_AGGRESSIVENESS = 1.0`
- `_FP_CRUISING_SPEED = 5.0` (m/s)
- `_FP_MTSCC_CURVATURE_CHECK = True`

### 5.2 开关总门控
- `curve_speed_control` 来自 plannerd。
- `controls_enabled` 来自 `controlsState.enabled`（若字段不存在则用 `selfdriveState.enabled`）。
- 若 `CP.openpilotLongitudinalControl == False` → 强制关闭曲线速度控制（仅 HUD 仍可能显示传统信息）。

### 5.3 参数读取（每 1s 刷新）
- `CurveSensitivity / 100.0` → `curve_sensitivity`
- `TurnAggressiveness / 100.0` → `turn_aggressiveness`
- `MapTurnControl / VisionTurnControl / MTSCCurvatureCheck` → 布尔开关

### 5.4 视觉曲率与触发判定
- 视觉曲率：`road_curvature = max(|orientationRate.z * velocity.x|) / max(v_ego, 1.0)^2`（数组为空或异常则置 0）。
- 触发条件：
  - `lat_accel_pred = |road_curvature| * max(v_ego, 1.0)^2 > _FP_CURVE_DETECT_LAT_A`
  - `v_ego > _FP_CRUISING_SPEED`
  - 左右转向灯均为 False

### 5.5 地图曲率与 MapTargetVelocities
- MapTargetVelocities 来源：`Params("/dev/shm/params").get("MapTargetVelocities")`（JSON list，raw 未变化则复用缓存）。
- 点解析：支持 `latitude/longitude` 或 `lat/lon/lng` 键，非法值直接丢弃。
- GPS 位置来源：`liveLocationKalman`，要求 `gpsOK && positionGeodetic.valid`。
- 写入 `/dev/shm/params/LastGPSPosition`（JSON，含 lat/lon/bearing）。
- `_fp_map_curvature()`：
  - 先找到“离当前定位最近”的点索引 `min_idx`（haversine 距离）。
  - `lookahead_dist = ModelConstants.T_IDXS[-1] * v_ego`。
  - 从 `min_idx` 开始向前遍历，**累加的是“当前点到车的位置距离”**（非相邻点段长），直到累计 ≥ `lookahead_dist`。
  - 取 `target_idx-1/target_idx/target_idx+1` 三点估曲率，返回 `max(curvature, 1e-6)`；点数不足或越界则返回 `1e-6`。
  - `self._map_min_dist_m` 记录最近点距离。

### 5.6 目标速度计算
- 仅当 `curve_speed_control == True` 时才读参数配置；否则 map/vision 目标直接等于 `v_cruise`。
- Map 目标（需满足 `curve_speed_control && map_enabled && controls_enabled && v_ego > _FP_CRUISING_SPEED`）：
  - `mtsc_active = (_fp_map_target < v_cruise)`（上一帧结果）
  - 若 `road_curvature_detected` 且 `mtsc_active` → 保持原 `_fp_map_target`。
  - 若 `!road_curvature_detected` 且 `fp_mtsc_check` → `map_target = v_cruise`。
  - 否则：`map_speed = sqrt((_FP_TARGET_LAT_A * turn_aggressiveness) / (map_curv * curve_sensitivity))`
    → `map_target = max(_FP_CRUISING_SPEED, map_speed)`。
- Vision 目标（需满足 `curve_speed_control && vision_enabled && controls_enabled && road_curvature_detected && v_ego > _FP_CRUISING_SPEED`）：
  - `vision_speed = sqrt((_FP_TARGET_LAT_A * turn_aggressiveness) / (abs(road_curvature) * curve_sensitivity))`
  - `vision_target = max(_FP_CRUISING_SPEED, vision_speed)`；否则回退到 `v_cruise`。
- Cluster 偏移（Ford 仪表速度）：
  - `v_cruise_cluster = max(v_cruise, vCruiseCluster * KPH_TO_MS)`（若无/异常则等于 v_cruise）
  - `v_cruise_diff = v_cruise_cluster - v_cruise`
  - **在判断限速来源之后**，`_fp_map_target` / `_fp_vision_target` 统一加上 `v_cruise_diff`。

### 5.7 最终限速与来源标记
- `v_cruise_pre_curve = v_cruise`
- `v_cruise = min([target if target > _FP_CRUISING_SPEED else v_cruise_pre_curve for target in [map_target, vision_target, v_cruise_pre_curve]])`
- `map_turn_limit_active = map_target < v_cruise_pre_curve`（在加 `v_cruise_diff` 前判断）
- `vision_turn_limit_active = vision_target < v_cruise_pre_curve`（在加 `v_cruise_diff` 前判断）
- `curveSpeedSource`：
  - Map+Vision 同时有效 → 取更低的一方决定来源（map<=vision → 2，否则 1）
  - 仅 Map → 2；仅 Vision → 1；否则 0
- `vTargetDEPRECATED`：
  - 当 map/vision 生效时：`min(map_target, vision_target)`
  - 无效或 <=0 则置 0

### 5.8 纵向提前减速
- 若 map/vision 限速生效：
  - `speed_ratio = v_ego / 22.2`
  - `cruise_min_accel = CRUISE_MIN_ACCEL - 1.2 * (1 - 1 / (1 + speed_ratio^2))`
  - 若 `dv = max(v_ego - curve_target, 0)` 且 `dv > 0.1` → `cruise_min_accel = min(cruise_min_accel, -dv/2.0)`

## 6. HUD 弯道图标与文字（`selfdrive/ui/onroad/hud_renderer.py`）
### 6.1 显示门槛
- `CurveSpeedControl == True` 且 `ShowCSCStatus == True`
- 已设定巡航速度（`is_cruise_set`）
- `v_ego >= 1 m/s`
- `modelV2` 必须是 onroad 后的最新帧（`sm.recv_frame["modelV2"] >= ui_state.started_frame`）
- `position/velocity/orientationRate` 三数组长度一致且非空
- `curveSpeedSource` ∈ {1,2} 且 `curve_target < set_speed`

### 6.2 目标速度与距离
- `curve_target` 优先来自 `vTargetDEPRECATED`；无效时取 `min(longitudinalPlan.speeds)`。
- 目标距离：沿 `ModelConstants.T_IDXS[:len(speeds)]` 积分速度；`idx_target` 为首个 `v <= curve_target + 0.05`，否则回退到最小速度位置 `idx_min`。
- 文案：
  - `目标 {speed} km/h|mph`
  - `前方弯道 {dist} m · 地图融合/视觉`

### 6.3 图标方向判定
- 使用 `orientationRate.z / velocity.x` 找最大曲率点（`v_pred` 先 clamp 到 `[max(1.0, v_ego*0.7), min(100.0, v_pred)]`）。
- 防抖：`k_dir_deadband=2e-4`，`hold_s=0.25`。
- 图标文件：
  - `icons/curve_speed.png`
  - `icons/curveR_speed.png`

### 6.4 字体
- 若中文缺字，动态加载 `unifont.otf`（与性能条逻辑一致），缓存 8 组。

## 7. 路径红色渐变提示（`selfdrive/ui/onroad/model_renderer.py`）
- `_update_curve_path_alert()`：
  - 依赖 `CurveSpeedControl` 与 `longitudinalPlan.curveSpeedSource`。
  - 若 map/vision 限速生效（`src_val in (1,2)`）：
    - `v_min = min(speeds)`，`drop_ratio = (v_ego - v_min) / max(v_ego * 0.35, 1.0)`。
    - `target = clip(drop_ratio, 0..1)`，并保证 `target >= 0.25`。
  - 若未限速：
    - `lat_accel_max = max(|orientationRate.z * v_pred|)`；
    - 当 `lat_accel_max > 0.5` → `target = max(target, clip((lat_accel_max - 0.5) / 1.5, 0..1))`。
- `sm.recv_frame["longitudinalPlan"] < ui_state.started_frame` 或异常 → `target=0`。
- `_draw_path()`：当 `_curve_path_alert > 0` 时叠加红色渐变。

## 8. 地图进程与离线数据（必要说明）
- `mapd` 在 `system/manager/process_config.py` 中常驻运行。
- mapd 二进制路径：`/data/media/0/osm/mapd`（自动下载/更新）。
- 离线地图路径：`/data/media/0/osm/offline`。
- maps_updater：依据 `MapsSelected` / `PreferredSchedule` 自动写入 `/dev/shm/params/OSMDownloadLocations` 并触发下载。

## 9. 复刻步骤（顺序不可变）
1. 注册参数键（CurveSpeedControl / CurveSensitivity / TurnAggressiveness / MapTurnControl / VisionTurnControl / MTSCCurvatureCheck / ShowCSCStatus）。
2. Lincoln 面板添加 UI 控件（含按钮文案、范围、默认值）。
3. plannerd 透传 `curve_speed_control` 到 `LongitudinalPlanner.update()`。
4. longitudinal_planner 实现曲率计算、map 读取、限速与 `curveSpeedSource/vTargetDEPRECATED` 发布。
5. HUD 实现弯道图标、目标速度、距离与方向判定。
6. model_renderer 实现路径红色渐变提示。
7. mapd + maps_updater 进程常驻与离线地图路径保持一致。

## 10. 验证清单
- 关闭 CurveSpeedControl 后：HUD 不显示弯道图标、路径红色渐变不出现。
- Map/Vision 切换后：`MapTurnControl/VisionTurnControl` 值正确变化。
- `curveSpeedSource` 在弯道中变为 1/2。
- 图标出现时 `curve_target < set_speed`，且距离与模型速度轨迹一致。
- Map 数据缺失时自动回退到 Vision。
