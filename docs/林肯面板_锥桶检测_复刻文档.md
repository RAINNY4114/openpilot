# 林肯面板：锥桶检测（Cone Detection, Experimental）复刻文档
## 0. 功能范围
- 开关 `dp_lat_cone_detection` 控制 HUD 显示；coned 在 `dp_lat_cone_detection` 或自动避让/自动超车开启时运行。
- coned 输出 `customReservedRawData0`（JSON bytes），HUD 绘制检测框/图标/邻道占用墙。
- 数据同时被自动避让/自动超车逻辑消费（见“下游依赖”）。

## 1. 必须涉及的文件清单
- `common/params_keys.h`
- `system/manager/process_config.py`
- `selfdrive/modeld/coned.py`
- `selfdrive/modeld/cone_detections.py`
- `selfdrive/modeld/lane_occupancy.py`
- `selfdrive/modeld/models/Cone_YOLO11n.onnx`
- `selfdrive/modeld/models/Cone_YOLO11n_tinygrad.pkl`
- `selfdrive/modeld/models/Cone_YOLO11n.MODEL.md`
- `selfdrive/ui/onroad/augmented_road_view.py`
- `selfdrive/ui/onroad/object_tracker.py`
- （下游）`selfdrive/modeld/modeld.py` / `selfdrive/controls/lib/longitudinal_planner.py`

## 2. 参数（`common/params_keys.h`）
- `dp_lat_cone_detection`：PERSISTENT BOOL，默认 `1`。

## 3. 进程门控（`system/manager/process_config.py`）
- `coned(started, params, CP)` → `return started and (dp_lat_cone_detection or dp_lincoln_auto_avoid or dp_lincoln_auto_overtake)`
- 仅 onroad 运行；HUD 是否显示由 `dp_lat_cone_detection` 决定。

## 4. coned 检测管线（`selfdrive/modeld/coned.py`）
### 4.1 模型与输入
- 模型文件（优先 ONNX）：`selfdrive/modeld/models/Cone_YOLO11n.onnx`
- 兼容回退：`selfdrive/modeld/models/Cone_YOLO11n_tinygrad.pkl`
- 类别表：`selfdrive/modeld/models/Cone_YOLO11n.MODEL.md`（COCO-80 + cone=80）
- 输入尺寸：`MODEL_INPUT_SIZE = 320`
- 摄像头流选择：
  - 优先 `VISION_STREAM_ROAD`，否则 `VISION_STREAM_WIDE_ROAD`。
- 像素格式：NV12 → RGB（`_nv12_to_rgb()`）。
- 预处理：letterbox 到 320×320（pad=(114,114,114)）。

### 4.2 关键环境变量（默认值）
- ONNX 运行：
  - `CONE_USE_ONNX = 1`
  - `CONE_ONNX_INTRA_THREADS = 0`（0=默认线程）
  - `CONE_ONNX_INTER_THREADS = 0`
- 置信度阈值：
  - `CONE_SCORE_MIN = 0.10`
  - `PERSON_SCORE_MIN = 0.25`
  - `VEHICLE_SCORE_MIN = 0.25`
  - `CONE_OTHER_SCORE_MIN = 0.25`
- inPath 面积阈值：
  - `CONE_PERSON_AREA_MIN_FRAC = 0.004`
  - `CONE_VEHICLE_AREA_MIN_FRAC = 0.010`
  - `CONE_TWOWHEEL_AREA_MIN_FRAC = 0.006`
- NMS：
  - `CONE_NMS_IOU = 0.45`
  - `CONE_MAX_DET = 64`
- 发布频率：`CONE_PUB_HZ = 20`
- 盒子细化（可选）：
  - `CONE_REFINE_EDGES = 1`
  - `CONE_REFINE_MAX_SIDE = 320`
  - `CONE_REFINE_PAD_FRAC = 0.08`
  - `CONE_REFINE_MIN_AREA_FRAC = 0.02`
  - `CONE_REFINE_IOU_MIN = 0.25`
  - `CONE_REFINE_MAX_OBJS = 32`
- metric 衰减：`CONE_METRIC_DECAY = 0.12`
- 邻道距离估计：
  - `CONE_LC_ASSUMED_VEHICLE_HEIGHT_M = 1.5`
  - `CONE_LC_ASSUMED_PERSON_HEIGHT_M = 1.7`
  - `CONE_LC_ASSUMED_CONE_HEIGHT_M = 0.7`
  - `CONE_LC_CONE_SCORE_MIN = 0.25`
  - `CONE_LC_LANE_Y_MIN_FRAC = 0.20`
  - `CONE_LC_LEFT_LANE_X_MIN_FRAC = 0.05`
  - `CONE_LC_LEFT_LANE_X_MAX_FRAC = 0.40`
  - `CONE_LC_RIGHT_LANE_X_MIN_FRAC = 0.60`
  - `CONE_LC_RIGHT_LANE_X_MAX_FRAC = 0.95`

### 4.3 输出类别
- `TRAFFIC_CONE_CLASS_IDX = 80`
- `PERSON_CLASS_IDX = 0`
- 车辆类：`{1,2,3,5,7}`（自行车/车/摩托/公交/卡车）

### 4.4 检测与筛选逻辑
- YOLO 输出：`out` shape `(85, 2100)`，`boxes_xywh` + `class_scores`。
- NMS：`CONE_NMS_IOU` + `CONE_MAX_DET`。
- `cones`：只用类 80，阈值 `CONE_SCORE_MIN`。
- `objs`：所有类；默认阈值 `CONE_OTHER_SCORE_MIN`，对 person/vehicle 使用专用阈值。
- 为 HUD 兼容：若 cones 未出现在 objs，则追加 cones（IoU < 0.60）。

### 4.5 inPath 与 metric
- ROI：`x in [0.35,0.65]*img_w` 且 `y2 >= 0.55*img_h`。
- `cone_in_path_raw`：基于 cones 的 ROI。
- `person_in_path_raw`/`vehicle_in_path_raw`：使用 `_dets_in_path()` + area_min_frac。
- Debounce：`_BoolDebouncer(on_cnt=2, off_cnt=3)`。
- metric：`_dets_metric()`（y 位置 + 面积归一化），随后 `metric_hold` 按 `CONE_METRIC_DECAY` 衰减。
- `obstacle_metric = max(cone_metric_hold, vehicle_metric_hold)`
- `hazard_metric = max(person_metric_hold, vehicle_metric_hold)`

### 4.6 邻道最小距离估计
- 使用原始 YOLO boxes（非 refined） + pinhole 估距：`dist = f_px * obj_height / bbox_height`。
- 左/右车道 ROI 由 `CONE_LC_*` 决定。
- 输出：`leftLaneHazDistM/rightLaneHazDistM`。

### 4.7 发布
- `PubMaster("customReservedRawData0")`
- 通过 `encode_cone_detections()` 写入 JSON bytes（不是 capnp 结构体）。

## 5. JSON 协议（`selfdrive/modeld/cone_detections.py`）
- 字段（v=1）：
  - `frameId`, `timestampSof`
  - `imgW`, `imgH`, `focalLengthPx`
  - `inPath`, `inPathRaw`
  - `hazInPath`, `hazInPathRaw`
  - `personInPath`, `personInPathRaw`
  - `vehicleInPath`, `vehicleInPathRaw`
  - `coneMetric`, `personMetric`, `vehicleMetric`
  - `obstacleMetric`, `hazMetric`
  - `leftLaneHazDistM`, `rightLaneHazDistM`
  - `cones`: `{x1,y1,x2,y2,s}`
  - `objs`:  `{c,x1,y1,x2,y2,s}`（原始）
  - `objsR`: `{c,x1,y1,x2,y2,s}`（refined）

## 6. HUD 绘制（`selfdrive/ui/onroad/augmented_road_view.py`）
### 6.1 显示门槛
- `dp_lat_cone_detection == 1` 才绘制。
- 依赖 `customReservedRawData0` 更新。
- `DET_STALE_TIMEOUT_S = 2.0` → 超时即清空。

### 6.2 绘制类与过滤
- `DP_DET_DRAW_ALL=1` → 绘制全部类别。
- 默认绘制：`{0,80} ∪ {1,2,3,5,7}`。
- 目标列表选择：优先 `objsR`，否则 `objs`；若两者为空但 `cones` 有值，则 UI 侧会将 cone 提升为 object 绘制。
- 颜色：
  - `DET_COLOR_CONE = (255,149,0,220)`
  - `DET_COLOR_PERSON = (0,170,255,220)`
  - `DET_COLOR_VEHICLE = (255,60,60,220)`
  - `DET_COLOR_SIGN = (255,220,0,220)`
  - `DET_COLOR_ANIMAL = (180,120,255,220)`
  - `DET_COLOR_OTHER = (220,220,220,200)`
- 标签背景透明度：`DET_LABEL_BG_ALPHA = 180`

### 6.3 目标跟踪
- `ObjectTracker`（`object_tracker.py`）默认参数：`iou_thres=0.30`、`max_missed=5`、`bbox_alpha=0.65`、`vel_alpha=0.60`、`score_alpha=0.60`。
- 时间轴：若 payload 含 `timestampSof`，追踪器用 SOF 秒时间更新；绘制时优先用当前帧 `timestamp_sof` 对齐，缺失则用 `time.monotonic()`。
- `DP_DET_SHOW_TRACK_ID` 为环境变量开关，默认 `0`（仅当设为 `1` 才显示 track id）。

### 6.4 距离显示
- `DP_DET_SHOW_DISTANCE` 为环境变量开关，默认 `0`（仅当设为 `1` 才显示 `dist_m`）。
- 估距：`dist = focalLengthPx * obj_height / bbox_height`（高度表：人 1.7m，车 1.5m，锥桶 0.7m），并裁剪到 0–250m。
- 若车道线可用，则以估计距离计算 `lane_dir`（左/本车道/右），车辆类会绘制方向箭头。

### 6.5 图标与绘制样式
- 车辆类：角点框 + 方向箭头（根据 lane_dir）。
- 行人：人形图标。
- 锥桶：锥桶图标。
- 其他：矩形框。
- 标签显示条件：车辆类或开启 track id/距离；且 `min(box_w, box_h) >= 35px` 才绘制文字标签。

## 7. 邻道“阻塞墙”绘制
- 需要 lane_lines_ok + focalLengthPx > 1.0。
- `compute_lane_occupancy()` 估算相邻车道最小距离。
- `compute_lane_occupancy(... score_min_vehicle=0.25, lane_margin_m=AUTO_LC_UI_LANE_MARGIN_M, side_close_dist_m=AUTO_LC_UI_SIDE_CLOSE_DIST_M)`。
- 常量：
  - `DP_LINCOLN_AUTO_LC_TGAP_S = 2.0`
  - `DP_LINCOLN_AUTO_LC_MIN_DIST_M = 25.0`
  - `DP_LINCOLN_AUTO_LC_MAX_DIST_M = 90.0`
  - `DP_LINCOLN_AUTO_LC_LANE_LINE_PROB_MIN = 0.30`
  - `DP_LINCOLN_AUTO_LC_LANE_MARGIN_M = -0.20`
  - `DP_LINCOLN_AUTO_LC_SIDE_CLOSE_DIST_M = 15.0`
  - `DET_COLOR_LANE_BLOCK = (255,149,0,255)`
- `target_lane_block_dist_m = clamp(v_ego * TGAP, MIN, MAX)`。
- `left/right_block` 条件：`min_dist_m` 在 `(0.1, target)` 或 `side_close=True`。
- 强度：`intensity = clip((target_lane_block_dist_m - d) / target_lane_block_dist_m, 0.25, 1.0)`。
