# 林肯面板：自动超车（Auto Overtake, Experimental）复刻文档
## 0. 功能定义
- 高速场景自动发起变道超车，并在满足条件后自动回到原车道。
- 仅注入“变道意图”，不改变纵向控制（ACC/openpilot 纵向仍由原逻辑决定）。

## 2. 参数（`common/params_keys.h`）
- `dp_lincoln_auto_overtake`：PERSISTENT BOOL，默认 `0`
- `dp_lincoln_lane_preference`：PERSISTENT INT，默认 `0`
  - 0=AUTO, 1=KEEP LEFT, 2=KEEP RIGHT

## 3. Lincoln 面板 UI（`selfdrive/ui/layouts/settings/lincoln.py`）
- Toggle：`Auto overtake` → `dp_lincoln_auto_overtake`

## 4. HUD 车道偏好按钮（`lane_pref_button.py` + `hud_renderer.py`）
### 4.1 显示门槛
- 仅当 `carParams.brand == "ford"` 且（`dp_lincoln_auto_avoid` 或 `dp_lincoln_auto_overtake`）开启时显示。

### 4.2 按钮行为
- 单击循环：`A -> L -> R`（写入 `dp_lincoln_lane_preference`）。
- 必须写入 **INT**（`Params.put_nonblocking`）。
- 说明：A/L/R 是车道偏好（AUTO/KEEP LEFT/KEEP RIGHT），不是“左/中/右车道选择”。

### 4.3 视觉样式（1:1）
- 背景：半透明黑 `rl.Color(0,0,0,110)`，圆形渐变。
- 文字：`A/L/R`，白色字体 + 黑色阴影。
- 强调环颜色：
  - AUTO：`(255,255,255,120)`
  - KEEP LEFT：`(0,122,255,160)`
  - KEEP RIGHT：`(255,149,0,160)`
- 半径与尺寸：`hud_renderer` 中 `UI_CONFIG.button_size * 0.85`。

### 4.4 HUD 位置
- 左侧列，介于“MAX 设定速度框”和“驾驶员监控图标”之间。
- X 与驾驶员监控图标中心对齐。

## 5. 自动超车状态机（`selfdrive/controls/lib/auto_overtake.py`）
### 5.1 常量
- `OVERTAKE_MIN_SPEED = 80 km/h`
- `OVERTAKE_MIN_CRUISE_SPEED = 90 km/h`
- `OVERTAKE_SPEED_DELTA = 10 km/h`
- `OVERTAKE_HEADWAY_MAX_S = 3.5`
- `OVERTAKE_LEAD_STABLE_SEC = 1.0`
- `PREPARE_BEFORE_LC_SEC = 0.6`
- `RETURN_CLEAR_DELAY_SEC = 5.0`
- `RETURN_MIN_TIME_AFTER_OUT_SEC = 4.0`
- `OVERTAKE_COOLDOWN_SEC = 20.0`
- `CLEAR_LANE_STABLE_SEC = 0.6`

### 5.2 触发条件（need_overtake）
- `lead_present=True` 且 `lead_d > 0`
- `v_cruise >= OVERTAKE_MIN_CRUISE_SPEED`
- `v_ego >= OVERTAKE_MIN_SPEED`
- `headway = lead_d / v_ego <= OVERTAKE_HEADWAY_MAX_S`
- `v_cruise - v_lead >= OVERTAKE_SPEED_DELTA`
- 条件持续 ≥ `OVERTAKE_LEAD_STABLE_SEC`

### 5.3 状态机
- `idle -> preparing -> changing_out -> holding/waiting_return -> changing_back`
- `preparing`：等待 `PREPARE_BEFORE_LC_SEC`
- `holding`：当 lane_preference 要求“保持超车道”时不回原车道
- `waiting_return`：need_overtake=False 且延迟满足后返回
- `cooldown`：完成后等待 `OVERTAKE_COOLDOWN_SEC`

### 5.4 方向选择
- LHD 默认左超车，RHD 默认右超车。
- `lane_preference` 仅影响是否返回原车道（KEEP LEFT/RIGHT 会保持超车道）。

### 5.5 手动转向灯门槛
- `manual_blinker=True` 且状态为 `idle` 时，不进入超车流程。

## 6. modeld 总门控（`selfdrive/modeld/modeld.py`）
### 6.1 启用条件
- `dp_lincoln_auto_overtake == 1`
- `latActive == True`
- `cruiseState.enabled == True`
- `bsm_available == True`

### 6.2 目标车数据来源
- `radarState.leadOne`（`status==True`）
- 若 `vLead` 无效 → `v_ego + vRel`

### 6.3 车道可用性门槛
- 基础条件：
  - BSM 可用（`carParams.enableBsm`）
  - blindspot == False
  - RoadEdgeDetector 未检测到路沿
- 说明：相邻车道占用判断基于视觉+车道线；前向无左/右侧传感器，BSM 仅后方盲区。
- 目标车道阻塞（来自 coned）：
  - `leftLaneHazDistM/rightLaneHazDistM < target_lane_block_dist_m` → 禁止变道
  - `target_lane_block_dist_m = clamp(v_ego * TGAP, MIN, MAX)`
  - `DP_LINCOLN_AUTO_LC_BLOCK_HOLD_SEC`：检测到阻塞后，保持禁用一段时间（默认 0.8s）
- 并行车辆阻塞：
  - `DP_LINCOLN_AUTO_LC_SIDE_Y2_MIN_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_AREA_MIN_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_X_GUARD_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_BLOCK_HOLD_SEC`

### 6.4 额外门槛（强制安全）
- `det_payload` 超过 1s 未更新或 lane_lines_ok_for_auto_lc=False → 禁止 *自动* 变道。
- 曲率保护：
  - `k_cur = abs(yawRate)/v_ego`
  - v0=22 m/s, v1=35 m/s, k0=0.004, k1=0.002
  - `k_cur > k_th` 且未打灯 → 禁止启动自动变道。

### 6.5 与自动避让优先级
- 若 `avoid_dir` 存在 → 优先于 `overtake_dir`。

### 6.6 变道完成冷却
- `DP_LINCOLN_AUTO_LC_POST_FINISH_COOLDOWN_SEC = 1.0`

### 6.7 自动打灯与 3 秒确认
- controlsd 在 `laneChangeState != off` 时自动打灯；仅自动变道会延迟打灯以保证语音领先。
- `AUTO_LC_BLINKER_DELAY_SEC = 0.3`（环境变量：`DP_AUTO_LC_BLINKER_DELAY_SEC`）。
- `AUTO_LANE_CHANGE_START_DELAY_SEC = 3.0 + AUTO_LC_BLINKER_DELAY_SEC`（自动变道 3 秒确认）。
- 相关文件：`selfdrive/controls/controlsd.py`、`selfdrive/controls/lib/desire_helper.py`、`selfdrive/ui/soundd.py`

## 7. 语音提示（`selfdrive/ui/soundd.py`）
- 文件：`selfdrive/assets/sounds/left-side.wav` / `right-side.wav`（若不存在，回退 `left.wav/right.wav`）。
- 播放条件：
  - `dp_lincoln_auto_avoid` 或 `dp_lincoln_auto_overtake` 启用。
  - `selfdriveState.enabled == True`。
  - `modelV2.meta.laneChangeState` 在 `preLaneChange` 或 `laneChangeStarting`。
  - preLaneChange 时如果**驾驶员打灯**则不播（避免重复）。
- 最小间隔：`MANEUVER_VOICE_MIN_INTERVAL_S = 2.0`

## 8. 复刻步骤
1. 注册参数键（`dp_lincoln_auto_overtake`、`dp_lincoln_lane_preference`）。
2. Lincoln 面板增加 `Auto overtake` 开关。
3. HUD 添加 lane_preference 按钮与样式（位置/大小/颜色一致）。
4. `auto_overtake.py` 实现状态机（含全部常量）。
5. `modeld.py` 接入 overtake 逻辑与所有安全门槛。
6. `soundd.py` 增加自动变道语音提示。

## 9. 验证清单
- 高速慢车场景满足条件进入 preparing。
- lane_preference=KEEP LEFT/RIGHT 时不自动回原车道。
- 车道阻塞或检测数据过期时不触发自动变道。
- 语音提示在 preLaneChange/Starting 阶段触发，且最小间隔生效。
