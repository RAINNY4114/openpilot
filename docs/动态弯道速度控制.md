# 林肯面板「动态弯道速度控制」功能实现（FP 1:1）

> 目标：与 FrogPilot 的曲率控制逻辑一致，统一参数与门控，移除旧版 Lincoln 专用逻辑。

## 1. 默认常量（代码）
**文件**：`selfdrive/controls/lib/longitudinal_planner.py`
- `_FP_TARGET_LAT_A = 2.0`
- `_FP_CURVE_SENSITIVITY = 1.0`
- `_FP_TURN_AGGRESSIVENESS = 1.0`
- `_FP_CRUISING_SPEED = 5.0`（m/s）

## 2. 参数（Params）
**文件**：`common/params_keys.h`
- `CurveSpeedControl`（BOOL，默认 1）
- `CurveSensitivity`（INT，默认 100 → 实际 1.00）
- `TurnAggressiveness`（INT，默认 100 → 实际 1.00）
- `MapTurnControl`（BOOL，默认 1）
- `VisionTurnControl`（BOOL，默认 1）
- `MTSCCurvatureCheck`（BOOL，默认 1）
- `ShowCSCStatus`（BOOL，默认 1）→ **仅控制 HUD 显示，不影响控制**

**mapd 相关（/dev/shm/params）**
- `MapTargetVelocities`（mapd 二进制输出）
- `LastGPSPosition`（mapd 线程与 `LongitudinalPlanner` 都会写）
- `GPSQualityOK`（mapd 线程写，用于 UI 质量门控）

## 3. UI 入口（Lincoln 面板）
**文件**：`selfdrive/ui/layouts/settings/lincoln.py`
- 「曲线检测方法」三选一：**基于地图 / 视觉 / 地图+视觉**
- **地图+视觉**：同时启用 `MapTurnControl=1` 与 `VisionTurnControl=1`，最终目标速度取更低者
- **基于地图** 与 **地图+视觉** 仅在离线地图已下载时可选；否则会提示并回退到 **视觉**

## 4. 数据输入与来源
**文件**：`selfdrive/controls/lib/longitudinal_planner.py`
- **视觉输入**：`modelV2.orientationRate.z` + `modelV2.velocity.x`
- **地图输入**：`MapTargetVelocities`（JSON list） + `liveLocationKalman`（GPS）
  - `liveLocationKalman` 取值条件：`gpsOK && status==valid && positionGeodetic.valid`
  - 方位：`bearing = degrees(calibratedOrientationNED.value[2])`
  - 写入：`LastGPSPosition` → `/dev/shm/params`
  - `MapTargetVelocities` 读取后会缓存；若 JSON 非 list 则视为无效
- `LastGPSPosition` 写入：  
  - `LongitudinalPlanner` 使用 `liveLocationKalman`（`gpsOK` + `status==valid` + `positionGeodetic.valid`）写入  
  - `mapd` 线程也会写入（见 `selfdrive/mapd/mapd.py`）

## 5. 算法细节（1:1）
**文件**：`selfdrive/controls/lib/longitudinal_planner.py`

### 5.1 视觉曲率计算
```python
orientation_rate = modelV2.orientationRate.z
velocity = modelV2.velocity.x
max_pred_lat_acc = max(orientation_rate * velocity, key=abs)
road_curvature = max_pred_lat_acc / v_ego**2
road_curvature_detected = (1.0 / abs(road_curvature))**0.5 < v_ego and v_ego > 5.0
road_curvature_detected &= not (leftBlinker or rightBlinker)
```

### 5.2 地图曲率计算
- `MapTargetVelocities` 为 JSON 列表，支持字段：`latitude/longitude` 或 `lat/lon/lng`
- 读取路径：`/dev/shm/params/MapTargetVelocities`（`Params("/dev/shm/params")`）
- 使用 haversine 计算点间距离，取**当前最近点**为起点  
- 以 `lookahead = ModelConstants.T_IDXS[-1] * v_ego` 累加距离，选 `p1,p2,p3`  
- 曲率 = `1 / radius`（三角形外接圆）

### 5.3 目标速度计算
```python
map_speed = sqrt((TARGET_LAT_A * turn_aggressiveness) / (map_curv * curve_sensitivity))
vision_speed = sqrt((TARGET_LAT_A * turn_aggressiveness) / (abs(road_curvature) * curve_sensitivity))
```
- `map_target = max(5.0, map_speed)`
- `vision_target = max(5.0, vision_speed)`

### 5.4 MTSCCurvatureCheck（地图前置）
- `MTSCCurvatureCheck=1` 且 **视觉未检测到弯道** 时：地图限速回退为 `v_cruise`

### 5.5 融合与 v_cruise_diff
```python
v_cruise = min(map_target, vision_target, v_cruise_pre_curve)
v_cruise_diff = v_cruise_cluster - v_cruise
map_target += v_cruise_diff
vision_target += v_cruise_diff
```
- **地图+视觉**：两者同时启用，取更低目标

### 5.6 curveSpeedSource
```python
if map_turn_limit_active: curveSpeedSource = 2
elif vision_turn_limit_active: curveSpeedSource = 1
else: curveSpeedSource = 0
```

## 6. 门控与触发条件
**文件**：`selfdrive/controls/plannerd.py` + `selfdrive/controls/lib/longitudinal_planner.py`
- `curve_speed_control = CP.openpilotLongitudinalControl && CurveSpeedControl`
- `controlsState.enabled == True`
- `v_ego > _FP_CRUISING_SPEED`（5 m/s）
- 转向灯未开启（视觉曲率检测阶段直接屏蔽）
- 地图限速：`MapTurnControl=1` 且 `MapTargetVelocities` 有效

## 7. HUD 显示
**文件**：`selfdrive/ui/onroad/hud_renderer.py`
- 触发条件：`CurveSpeedControl=1` 且 `ShowCSCStatus=1`
- 来源：`curveSpeedSource`（地图/视觉）
- 目标速度：`longitudinalPlan.speeds` 的最小值
