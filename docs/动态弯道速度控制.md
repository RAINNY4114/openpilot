# 林肯面板「动态弯道速度控制」功能实现（1:1 复刻版）

> 目标：在其它分支中 **1:1 复刻** Lincoln/Ford（非 CAN FD）“动态弯道限速/弯前自动减速”功能。本文按文件路径列出所有涉及的代码与逻辑，按顺序逐项移植即可。
>
> 说明：调试日志是**独立功能**，请另见 `docs/弯道速度控制日志.md`。

---

## 0. 功能概览（输入/输出/前提）

- **输入**：视觉模型 `modelV2` 的前向轨迹与偏航角速度预测：
  - `modelV2.position.x`（前向距离，m）
  - `modelV2.velocity.x`（预测速度，m/s）
  - `modelV2.orientationRate.z`（预测 yaw rate，rad/s）
- **核心计算**：预测曲率 `k = |yaw_rate| / v`，并在前方窗口内取“峰值+平滑+滞回”，得到目标弯速：
  - `v_limit_raw = sqrt(a_lat / k_smooth)`
- **输出（控制侧）**：当 `v_limit < v_cruise`（HUD 出现弯道减速图标）时：
  - 生成 `curve_v_target`（m/s）并让 `v_cruise = min(v_cruise, curve_v_target)`（速度上限逐步收紧）
  - 同时把 `required_decel` 作为 `aTarget` 的下限（`output_a_target = min(output_a_target, required_decel)`），确保弯道图标出现后车辆真的开始减速，而不是只“显示提示”
- **HUD 提示（UI）**：由 `selfdrive/ui/onroad/hud_renderer.py` 绘制；上行末尾显示来源标记（`视觉/地图融合`），来源于 `longitudinalPlan.curveSpeedSource`；蓝色信息框宽度按文本测量自动扩展（最小 `widget_size * 2`），避免长文案溢出到背景框外。
  - 上行：`前方弯道 {N} m · 视觉` / `前方弯道 {N} m · 地图融合`（距离单位始终为 m）
  - 下行：`目标 {S} km/h`（或 `mph`，取决于 `IsMetric`；`S` 为弯道限速目标值，不是当前车速）
- **车型门控**：仅在 `CP.brand == "ford"` 且面板开关 `dp_lincoln_curve_speed=1` 时启用控制（日志开关见另文档）。
- **生效前提**：
  - 若 `CP.openpilotLongitudinalControl=True`（OpenPilot 纵向接管）：需要 `controlsState.longActive=True` 才能通过 `aTarget` 直接控制减速。
  - 若 `CP.openpilotLongitudinalControl=False`（Ford/Lincoln 常见原车 ACC）：`controlsState.longControlState` 可能长期为 `off`，但弯道控速仍可通过收紧 `v_cruise` 去“请求更低的原车设定巡航速度”实现减速；因此 HUD 的来源标记不应门控在 `longControlState/off` 或 `longActive` 上。
- **地图弯道预限速（可选）**：当开启 `dp_lincoln_osm_realtime_cruise=1` 且 `MapTargetVelocities` 有效时，地图输出会参与压低 `v_cruise`（并提供 `map_a_target` 下限确保真的减速）；同时在长弯/S 弯等场景下，会用“当前路段的地图速度上限”做持续限速（防止弯中回加速），并对目标点做锁定直到通过（降低抖动/误释放）。另外会做“前瞻限速 cap”：仅当未来约 10s（80~400m）内已经出现需要限速的地图路段时，才启用更长的约 20s（120~800m）窗口取“最低地图目标速度”来压住 `v_cruise`，减少连续弯/S 弯场景中后段再二次下压导致的“分段式减速”体感；并且对 preview cap 做“快收紧、慢放松”平滑以降低抖动。`map_a_target` 的最小减速度也会随 `v_ego - v_target` 逐渐衰减到 0，避免接近目标速度时出现硬性的 `-0.30 -> 0` 松刹跳变。视觉弯道限速仍作为并行兜底，两者取更保守的结果。

## 1. 参数声明（Params Keys）

- **文件**：`common/params_keys.h`
- **新增键（弯道控制相关共 5 个；其中日志开关见另文档）**：
  ```cpp
  {"dp_lincoln_curve_speed", {PERSISTENT, BOOL, "0"}},
  {"dp_lincoln_curve_log", {PERSISTENT, BOOL, "0"}},
  {"dp_lincoln_curve_window_m", {PERSISTENT, INT, "130"}},
  {"dp_lincoln_curve_k_enter", {PERSISTENT, INT, "4"}},       // 存储 1e-3 曲率阈值，默认 0.004
  {"dp_lincoln_curve_decel", {PERSISTENT, INT, "-320"}},      // 存储 cm/s^2，默认 -3.20 m/s^2
  ```

- **地图模式相关键（OSM/mapd）**：
  ```cpp
  {"dp_lincoln_osm_realtime_cruise", {PERSISTENT, BOOL, "0"}},
  {"LastGPSPosition", {PERSISTENT, STRING}},
  {"MapTargetVelocities", {PERSISTENT, STRING}},
  ```
  - `MapTargetVelocities` 由 `mapd` 持续写入（通常在 `/dev/shm/params`），供纵向规划做弯道预限速计算。

### 1.1 三个“可调参数”（面板暴露）

1) **曲率前瞻距离** `dp_lincoln_curve_window_m`  
   - 单位：m（整数）
   - 默认：`130`
   - 作用：看得越远越可能提前触发减速；太小会导致“进弯/弯心才开始减速”。

2) **进入曲率阈值** `dp_lincoln_curve_k_enter`  
   - 存储：整数，表示 `k_enter * 1000`（m⁻¹）
   - 默认：`4` → `0.004`
   - 作用：阈值越小越敏感，越容易提前触发；太小可能直路也误触发。

3) **弯前最大减速度** `dp_lincoln_curve_decel`  
   - 存储：整数，表示 `decel(m/s²) * 100`（cm/s²）
   - 默认：`-320` → `-3.20 m/s²`
   - 作用：允许的预刹强度上限（越负越“早/猛”）；太大可能带来舒适性下降。

### 1.2 算法里未暴露到面板的固定量（必须保持一致）

这些量不在面板里，但会显著影响行为，复刻时请保持一致：

- `k_exit = 0.70 * k_enter`（固定比例，退出阈值比进入阈值更低，形成滞回）
- `a_lat = 1.8 m/s²`（舒适侧向上限固定）
- `exit_h = 0.70 s`（退出滞回计时固定）

## 5. 核心算法（LongitudinalPlanner）

> 文件：`selfdrive/controls/lib/longitudinal_planner.py`  
> 复刻时建议直接整体复制以下改动块，避免漏掉“触发更早/点刹抑制/约束生效”的关键细节：
> - `LongitudinalPlanner.__init__`：新增状态与日志路径
> - `LongitudinalPlanner._lincoln_curve_config()`
> - `LongitudinalPlanner._apply_lincoln_curve_speed(...)`
> - `LongitudinalPlanner.update(...)`：调用入口 + 曲线状态强收紧 + 日志落盘时机

### 4.1 初始化新增状态（必须一并带走）

```python
# Lincoln/Ford 专用弯道限速状态
self.curve_k_smooth = 0.0
self.curve_active = False
self.curve_v_target = None
self.curve_exit_timer = 0.0
self.last_curve_log_t = 0.0
self.curve_log_dir = "/data/media/0/lincoln_curve_logs"
self._params = Params()
self._curve_cfg = {}
self._curve_param_last = 0.0
self._curve_log_pending = None
self._curve_log_fname = None
self._curve_log_header = None
```

### 4.2 参数加载与内部固定量

```python
window_m = max(30, min(190, ...))
k_enter = (k_enter_milli * 1e-3)
k_exit = k_enter * 0.70
a_lat = 1.8
decel_max = clamp(dp_lincoln_curve_decel, [-5.0, -0.5])
exit_h = 0.70
```

注意：配置读取做了 1s 缓存（避免每帧读 Params），以及更宽的内部夹逼（例如 `k_enter` 最多允许到 `0.020`），复刻时以代码为准。

### 4.3 关键流程（为什么能“弯前”减速）

1) **预测曲率序列**  
   `k = |yaw_rate| / v`，并强制 `k <= 0.02`（Ford 非 CAN FD 下发/安全限幅量程）  
   其中 `v` 取预测速度 `v_pred`，但下限为 `max(1.0, v_ego*0.7)`，避免 `v_pred` 偶发过小导致曲率虚高（高速轻微弯道误触发猛刹/连续减速）。

2) **前瞻窗口与“峰值选取”修复**  
   - 只看 `position <= window_m`
   - 选峰值时忽略前 5m，避免 `critical_distance≈0` 导致触发距离过近/不触发

3) **平滑 + 进入/退出滞回**  
    - `curve_k_smooth = 0.6*k_max + 0.4*prev`
    - `k_enter/k_exit` 固定（不随速度变化）
    - `exit_h=0.70s` 退出计时，避免出弯抖动

4) **目标弯速与“图标出现即减速”**  
   - `v_limit = sqrt(a_lat / k_smooth)`
   - 当 `v_limit < v_cruise` 时：初始化 `curve_v_target`，并按 `required_decel` 每帧下滑到 `v_limit`；同时 `v_cruise = min(v_cruise, curve_v_target)`，Long MPC 会立刻开始平滑减速（不再等待其它剪裁生效）。

5) **预刹距离与等效减速度**  
    - `trigger_distance`：优先取“首次超过阈值”的点；并提供“累计弯度 bend”提前触发
    - `d_use = max(trigger_distance, v_ego*1.5, 1.0)`
    - `required_decel = (v_target^2 - v_ego^2) / (2*d_use)` 并受 `dp_lincoln_curve_decel` 约束

### 4.4 update() 内的调用位置与“强收紧”速率

- **调用位置/融合逻辑**：视觉弯道限速始终可用；地图弯道预限速在“真正限速”时作为额外上限参与融合（并提供 `aTarget` 下限确保真的减速）：
  ```python
  # map target (optional)
  if lincoln_osm_realtime_cruise:
    v_map_target, map_a_target = ...

  # vision curve (always available when enabled)
  if lincoln_curve_speed:
    accel_clip, v_cruise = self._apply_lincoln_curve_speed(sm, accel_clip, v_cruise, ...)

  # map clamp (active only when it tightens current v_cruise)
  map_turn_limit_active = v_map_target > 0.1 and v_map_target < (v_cruise - 1e-3)
  if lincoln_osm_realtime_cruise and map_turn_limit_active:
    v_cruise = min(v_cruise, v_map_target)

  # ensure real decel (optional)
  if lincoln_curve_speed and curve_a_target < -1e-3:
    output_a_target = min(output_a_target, curve_a_target)
  if lincoln_osm_realtime_cruise and map_turn_limit_active and map_a_target < -1e-3:
    output_a_target = min(output_a_target, map_a_target)
  ```

## 7. 行为摘要（用户可感知的“弯前减速”来自哪里）

- **更早触发**：更长的前瞻窗口 + “首次过阈值点/累计弯度”触发 + 忽略前 5m 峰值防止晚刹
- **更连续的减速**：`curve_v_target` 按 `required_decel` 逐步下滑到 `v_limit`（图标出现即开始），避免“先不减速/后突然点刹”
- **地图融合（如启用）**：`dp_lincoln_osm_realtime_cruise=1` 且地图输出有效时，地图会参与压低 `vCruise`，并对 `aTarget` 施加减速下限；此外会用“当前路段速度上限”在弯道内持续限速，并锁定目标点直到通过以减少抖动。视觉弯道限速仍作为并行的安全兜底（两者取更保守的结果）。
