# 自动超车（高速，dp_lincoln_auto_overtake）复刻文档

> 目标：让其他人/其他 AI 仅通过本文档（含文件路径与关键标识符）即可在另一份 openpilot 代码中 **1:1 复刻** 当前仓库的“高速自动超车”功能实现。

> 安全提示：实验性功能，仅用于合规/安全环境测试；驾驶员必须全程监控并随时接管。本功能只注入变道意图，不保证一定完成超车/回正。

---

## 0. 功能定义（按代码）

本功能是“**高速场景的自动变道超车**”，触发来源为 `radarState.leadOne` 的慢车（lead）信息。它只做一件事：

- **向 openpilot 的变道状态机注入变道意图**（`Desire.laneChangeLeft/Right`）
- **不直接控制纵向加速/减速**（纵向仍由原车 ACC / openpilot 纵向控制决定）

对应代码注释：`selfdrive/controls/lib/auto_overtake.py` 顶部注释。

## 3. 触发条件（严格按代码，含常量名）

### 3.1 硬门控（任一不满足：状态机 reset，绝不触发）

硬门控发生在两处：

1) `modeld` 侧（决定是否调用/启用）
- `dp_lincoln_auto_overtake==1`
- `carControl.latActive==True`
- `carState.cruiseState.enabled==True`
- 弯道门禁：当 `laneChangeState==off` 且曲率（`yawRate/vEgo`）超过速度相关阈值时，不会发起自动超车变道（`selfdrive/modeld/modeld.py`）

2) `AutoOvertakeHelper.update()` 内部（再次门控）
- `bsm_available==True`
- `vEgo >= OVERTAKE_MIN_SPEED`（默认 `80 km/h`）
- `v_cruise >= OVERTAKE_MIN_CRUISE_SPEED`（默认 `90 km/h`）
- 驾驶员手动转向灯（只在 `idle` 阻止启动）：`manual_blinker==True` 且 `mode=="idle"` 时直接不启动自动超车
  - `manual_blinker = (carState.leftBlinker != carState.rightBlinker)`

常量定义：`selfdrive/controls/lib/auto_overtake.py`

### 3.2 慢车触发（need_overtake，满足并稳定后才开始超车）

触发来源：`radarState.leadOne`

需要满足（默认值见 `auto_overtake.py` 常量）：

- `lead_present == True`（`leadOne.status==True`）
- `lead_d > 0`
- `headway = lead_d / v_ego <= OVERTAKE_HEADWAY_MAX_S`（默认 `3.5s`）
- `(v_cruise - v_lead) >= OVERTAKE_SPEED_DELTA`（默认 `10 km/h`）
- 连续满足 `>= OVERTAKE_LEAD_STABLE_SEC`（默认 `1.0s`）

> 说明：当前实现使用 `headway = dRel / vEgo` 作为“接近到会被限速”的粗门限；并未使用 TTC（`dRel/(vEgo-vLead)`）做更强约束。

## 4. 变道方向与“可变道”判断（严格按代码）

### 4.1 超车方向（按交通规则）

在 `AutoOvertakeHelper.update()` 中：

- `is_rhd == False`（左舵/LHD）：默认 **向左超车**（`pass_dir = left`）
- `is_rhd == True`（右舵/RHD）：默认 **向右超车**（`pass_dir = right`）

### 4.2 车道可用（left_ok/right_ok）

`modeld` 计算：

- `bsm_available = carParams.enableBsm`
- `left_ok = bsm_available and (not carState.leftBlindspot) and (not left_edge_detected)`
- `right_ok = bsm_available and (not carState.rightBlindspot) and (not right_edge_detected)`

其中 `left_edge_detected/right_edge_detected` 来自 `RoadEdgeDetector`（`dragonpilot.selfdrive.controls.lib.road_edge_detector`）。

目标车道前方占用门控（增强）：
- `coned` 会输出 `payload.objs[]`（全类别 bboxes）以及 `payload.focalLengthPx`（可选，用于距离估算）
- 同时保留一个“固定 ROI 粗估”的 `leftLaneHazDistM/rightLaneHazDistM`（单位 m，`0.0` 表示无/不可用，作为 fallback）
- `modeld` 在 `laneLines[1]/laneLines[2]` 置信度足够时，会把 `objs[]` 按车道线边界做左右车道归属，并用 bbox 高度做 pinhole 粗距离估算，得到更精细的左右车道最小距离
- 最终用于收紧 `left_ok/right_ok` 的距离会取更保守结果（min non-zero），避免“目标车道前方有车还自动变道”
- `target_lane_block_dist_m = clamp(vEgo * 2.0s, [25m, 90m])`
  - 若 `left/right` 距离在该范围内，则对应侧 `left_ok/right_ok` 强制为 False
  - 抗漏检“阻塞保持”：`DP_LINCOLN_AUTO_LC_BLOCK_HOLD_SEC`（默认 `0.8s`）
  - 车道线门槛/保守性可调：`DP_LINCOLN_AUTO_LC_LANE_LINE_PROB_MIN`、`DP_LINCOLN_AUTO_LC_LANE_MARGIN_M`
  - 新增安全门控：仅当检测数据新鲜（`customReservedRawData0` <= 1s）且车道线置信度满足门槛时才允许**自动**起步变道；否则禁止 `overtake_dir/avoid_dir`（不影响手动打灯、不取消进行中变道）

侧方并行车辆保护（新增，视觉兜底）：
- 背景：BSM 主要覆盖后方盲区，容易漏掉“并行/略靠前”的车辆；因此 `modeld` 会从 YOLO 的 `objsR/objs` 中额外检测画面左右侧的“近距离大目标”（车辆/行人/两轮等），若检测到则短时间内禁止向该侧发起**自动**变道请求。
- 代码：`selfdrive/modeld/modeld.py`
- 环境变量（默认值）：
  - `DP_LINCOLN_AUTO_LC_SIDE_BLOCK_HOLD_SEC=1.2`
  - `DP_LINCOLN_AUTO_LC_SIDE_Y2_MIN_FRAC=0.70`
  - `DP_LINCOLN_AUTO_LC_SIDE_AREA_MIN_FRAC=0.02`
  - `DP_LINCOLN_AUTO_LC_SIDE_X_GUARD_FRAC=0.06`
  - `DP_LINCOLN_AUTO_LC_SIDE_CLOSE_DIST_M=15.0`（基于车道线归属 + 距离估算的“并行近车”额外兜底阈值）

变道后冷却（新增）：
- 目的：避免“变道刚完成就又触发下一次自动变道”（例如与旁车平行时误触发回正/再次变道）。
- 行为：当 `laneChangeState` 从 `laneChangeFinishing -> off` 时，`modeld` 会在短时间内屏蔽新的自动避让/自动超车变道请求。
- 环境变量：`DP_LINCOLN_AUTO_LC_POST_FINISH_COOLDOWN_SEC=1.0`

稳定性去抖：
- `AutoOvertakeHelper` 会对 `left_ok/right_ok` 做 `CLEAR_LANE_STABLE_SEC`（默认 `0.6s`）连续为 True 的判定，得到 `left_stable/right_stable`，再作为 `pass_ok/return_ok`

> 结论：当前实现的“可超车道安全性”= **盲点无车 + 无路沿边缘 + 目标车道前方无占用（车道线归属 + 粗距离估算 + fallback）**（并不包含后车逼近速度等高级策略）。

## 5. 状态机（严格按代码）

文件：`selfdrive/controls/lib/auto_overtake.py`

状态：
- `idle`
- `preparing`
- `changing_out`
- `holding`（保持超车侧，不自动回正）
- `waiting_return`
- `changing_back`

与“偏好车道”参数的关系：
- 参数键：`dp_lincoln_lane_preference`（int，HUD 单按钮循环切换）
  - `0`：AUTO（默认）→ 超车完成后进入 `waiting_return`，满足条件自动回正
  - `1`：KEEP LEFT → LHD 下超车完成后进入 `holding`（不自动回正）
  - `2`：KEEP RIGHT → RHD 下超车完成后进入 `holding`（不自动回正）

关键行为：

1) 发起超车前准备（抗抖）
- `need_overtake==True` 且超车侧 `pass_ok==True`
- 等待 `PREPARE_BEFORE_LC_SEC`（默认 `0.6s`）

2) 发起超车
- 在 `changing_out` 中会持续“保持请求”，直到变道状态机开始进入变道流程

3) 回正（回到原车道）
- `need_overtake==False` 连续 `>= RETURN_CLEAR_DELAY_SEC`（默认 `5.0s`）
- 且超车完成后至少 `RETURN_MIN_TIME_AFTER_OUT_SEC`（默认 `4.0s`）
- 且原车道侧 `return_ok==True`

4) 冷却
- 一次往返完成后冷却 `OVERTAKE_COOLDOWN_SEC`（默认 `20s`）

## 6. 与“障碍物自动避让（dp_lincoln_auto_avoid）”的优先级

实现位置：`selfdrive/modeld/modeld.py`

当“自动避让”与“自动超车”同时产生变道请求时：

- **自动避让优先**（只要 `avoid_dir != none`，就忽略 `overtake_dir`）
- `auto_dir = avoid_dir if avoid_dir != none else overtake_dir`

## 7. 语音播报（避让/超车共用一套左右音频）

### 7.1 音频文件

- `selfdrive/assets/sounds/left-side.wav`
- `selfdrive/assets/sounds/right-side.wav`

注意不要与盲点语音混淆：
- 盲点语音是 `selfdrive/assets/sounds/left.wav`、`selfdrive/assets/sounds/right.wav`
- 变道（自动避让/自动超车）语音是 `selfdrive/assets/sounds/left-side.wav`、`selfdrive/assets/sounds/right-side.wav`

要求（与仓库现有音频一致）：
- 单声道（1 channel）
- 16-bit（sampwidth=2）
- 48kHz（framerate=48000）

### 7.2 播报触发（严格按代码）

文件：`selfdrive/ui/soundd.py`

触发时机：
- `selfdriveState.enabled==True`
- 且（`dp_lincoln_auto_avoid==1` 或 `dp_lincoln_auto_overtake==1`）
- 自动变道优先：`laneChangeState` 从 `off` → `preLaneChange` 且当时没有手动打灯
- 兜底：`laneChangeState` 进入 `laneChangeStarting`
- 按 `laneChangeDirection` 播放 left/right 对应语音

去抖：
- 最小间隔 `MANEUVER_VOICE_MIN_INTERVAL_S`（默认 `2s`）

## 9. 验收（最小可复现）

1) 车辆条件满足：BSM 可用、巡航开启、车速/巡航高于门限
2) 前车慢：`radarState.leadOne.status==True` 且速度差达到门限，并接近到 headway 门限内
3) 左/右盲区无车、无路沿边缘，且目标车道前方无占用：`left_ok/right_ok` 为 True（稳定）
4) 观察：
   - `modelV2.meta.laneChangeState/laneChangeDirection` 进入变道
   - 触发左右语音播报（`left-side.wav/right-side.wav`）
   - 超车完成后在“无需超车”持续一段时间后回正
