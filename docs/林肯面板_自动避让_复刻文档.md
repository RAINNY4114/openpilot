# 林肯面板：自动避让（Auto Avoidance, Experimental）复刻文档
## 0. 功能定义
- 当检测到锥桶/车辆/行人进入本车道时：
  - 先限速减速；
  - 满足条件时自动变道绕行；
  - 障碍消失后返回原车道。
- 行人触发 **停车**（不尝试自动变道）。

## 1. 必须涉及的文件清单
- `common/params_keys.h`
- `selfdrive/ui/layouts/settings/lincoln.py`
- `selfdrive/modeld/coned.py`
- `selfdrive/modeld/cone_detections.py`

- `selfdrive/controls/lib/longitudinal_planner.py`
- `selfdrive/ui/soundd.py`

## 2. 参数与默认值（`common/params_keys.h`）
- `dp_lincoln_auto_avoid`：PERSISTENT BOOL，默认 `0`
- `dp_lat_cone_detection`：PERSISTENT BOOL，默认 `1`（HUD 显示开关；auto avoid/auto overtake 也会拉起 coned）
- `dp_lincoln_lane_preference`：PERSISTENT INT，默认 `0`（自动避让 **不使用**，仅自动超车用）
- `dp_lincoln_hazard_alert`：PERSISTENT BOOL，默认 `0`（当前未接入；soundd 内部强制开启 hazard chime）

## 3. Lincoln 面板 UI（`selfdrive/ui/layouts/settings/lincoln.py`）
- 分组：`### Obstacle Avoidance (Experimental) ###`
- Toggle：`Cone Detection (Experimental)` → `dp_lat_cone_detection`
  - 关闭时：coned 仍可被 auto avoid/auto overtake 拉起，但 HUD 不绘制目标框。
- Toggle：`Auto avoidance` → `dp_lincoln_auto_avoid`
  - 描述：`When cones/vehicles are detected in-path, automatically slow down then initiate a lane change to pass, and return when clear. Pedestrians trigger a stop (no auto lane change). Experimental and requires blindspot sensors.`

## 4. 纵向减速逻辑（`selfdrive/controls/lib/longitudinal_planner.py`）
### 4.1 关键常量
- `OBSTACLE_DET_STALE_TIMEOUT_S = 1.0`
- `OBSTACLE_DET_CONFIRM_S = 1.0`
- `OBSTACLE_CONFIDENCE_MIN = 0.8`
- `OBSTACLE_CONE_CONF_MIN = 0.95`
- `OBSTACLE_LANE_PROB_MIN = 0.4`
- `OBSTACLE_LANE_MARGIN_M = 0.1`
- `OBSTACLE_SLOW_SPEED_MPH = 12.0`
- `OBSTACLE_APPROACH_SPEED_MPH = 35.0`
- `OBSTACLE_STOP_DELAY_S = 3.0`
- `OBSTACLE_METRIC_START = 0.15`
- `OBSTACLE_METRIC_FULL = 0.75`
- `OBSTACLE_V_CAP_DOWN_RATE = 8.0` (m/s^2)
- `OBSTACLE_V_CAP_UP_RATE = 2.0` (m/s^2)

### 4.2 检测数据来源
- 来自 `customReservedRawData0`（coned JSON）。
- `inPath` 需与 `inPathRaw` 同时为 True 才算有效；`personInPath` 与 `personInPathRaw` 同理；`vehicleInPath` 与 `vehicleInPathRaw` 同理。
- 若检测数据超过 1s 未更新 → 全部清零。

### 4.3 Ego 车道确认
- `compute_ego_lane_occupancy()`
  - 仅当 `laneLineProbs[1]`、`laneLineProbs[2] >= OBSTACLE_LANE_PROB_MIN` 才计算。
  - `lane_margin_m = OBSTACLE_LANE_MARGIN_M`。
- 若 `obstacle_lane_conf == True`，必须处于本车道才算障碍。

### 4.4 确认逻辑
- `obstacle_present` → `obstacle_conf` 需 ≥ 阈值并持续 `OBSTACLE_DET_CONFIRM_S`。
- 仅“锥桶”时使用更高阈值 `OBSTACLE_CONE_CONF_MIN`。

### 4.5 限速/停车
- 触发条件：`dp_lincoln_auto_avoid == True` 且 `selfdriveState.enabled == True` 且障碍确认。
- 行人：`v_cap_target = 0`（停车）。
- 锥桶/车辆：
  - 只有 `CP.enableBsm == True` 才会执行减速 + 变道协同；否则 `v_cap_target` 保持 0（直接停车）。
  - `obstacle_metric` 在 `[0.15,0.75]` 区间线性插值：
    - 低于 0.15 → 35 mph
    - 高于 0.75 → 12 mph
  - 若持续 ≥ `OBSTACLE_STOP_DELAY_S` 且变道未开始（laneChangeState=off/pre） → `v_cap_target = 0`
- 速率限制：
  - 降速速度 `8 m/s^2`，回升速度 `2 m/s^2`。

## 5. 自动避让状态机（`selfdrive/controls/lib/auto_avoidance.py`）
### 5.1 常量
- `AUTO_AVOID_MIN_SPEED = 30 km/h`
- `SLOWDOWN_BEFORE_LC_SEC = 1.0`
- `OBSTACLE_CLEAR_DELAY_SEC = 2.0`
- `RETURN_MIN_TIME_AFTER_OUT_SEC = 3.0`
- `AVOID_COOLDOWN_SEC = 8.0`
- `CLEAR_LANE_STABLE_SEC = 0.6`

### 5.2 状态机
- `idle -> slowing -> changing_out -> waiting_return -> changing_back`
- `manual_blinker=True` 且处于 `idle` → 不进入流程。
- `bsm_available=False` 或 `v_ego < AUTO_AVOID_MIN_SPEED` → 强制 reset（不变道）。

### 5.3 方向选择
- `prefer_dir` 来自障碍物横向偏移（modeld 计算）。
- 左右皆可时：LHD 默认左，RHD 默认右。
- 若选定车道变得不可用，允许一次切换到另一侧。

## 6. modeld 总门控（`selfdrive/modeld/modeld.py`）
### 6.1 触发阈值（环境变量）
- `DP_LINCOLN_AVOID_CONE_METRIC_MIN = 0.25`
- `DP_LINCOLN_AVOID_VEHICLE_METRIC_MIN = 0.45`
- `DP_LINCOLN_AVOID_VEHICLE_METRIC_MIN_NO_LEAD = 0.65`
- `DP_LINCOLN_AVOID_STOPPED_LEAD_SPEED_MS = 3.0`

### 6.2 obstacle_in_path_for_avoid
- cone：`cone_in_path && cone_metric >= AVOID_CONE_METRIC_MIN`
- vehicle：
  - 有 lead 且 `v_lead < AVOID_STOPPED_LEAD_SPEED_MS`：`vehicle_metric >= AVOID_VEHICLE_METRIC_MIN`
  - 无 lead：`vehicle_metric >= AVOID_VEHICLE_METRIC_MIN_NO_LEAD`

### 6.3 避让方向偏好
- 使用 `customReservedRawData0` 的 bbox 估计障碍横向偏移：
  - 取 ROI 中 `y2` 最大的 obj（cls=0/1/2/3/5/7/80）。
  - `offset = (cx - 0.5*img_w) / (0.5*img_w)`
  - `offset > 0.10` → prefer left；`offset < -0.10` → prefer right。

### 6.4 车道可用性门槛
- 基础条件：BSM 可用、blindspot=False、RoadEdgeDetector 未触发。
- 目标车道阻塞：
  - `DP_LINCOLN_AUTO_LC_TGAP_S / MIN_DIST / MAX_DIST`
  - `leftLaneHazDistM/rightLaneHazDistM < target_lane_block_dist_m` → 禁止变道
  - `DP_LINCOLN_AUTO_LC_BLOCK_HOLD_SEC`：检测到阻塞后，保持禁用一段时间（默认 0.8s）
- 并行车辆阻塞：
  - `DP_LINCOLN_AUTO_LC_SIDE_Y2_MIN_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_AREA_MIN_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_X_GUARD_FRAC`
  - `DP_LINCOLN_AUTO_LC_SIDE_BLOCK_HOLD_SEC`
- 车道线可信度：`laneLineProbs[1/2] >= DP_LINCOLN_AUTO_LC_LANE_LINE_PROB_MIN`

### 6.5 曲率保护
- `k_cur = abs(yawRate)/v_ego`
- v0=22 m/s, v1=35 m/s, k0=0.004, k1=0.002
- `k_cur > k_th` 且未打灯 → 禁止启动自动变道

### 6.6 变道总仲裁
- `auto_dir = avoid_dir if avoid_dir != none else overtake_dir`
- 自动避让优先级高于自动超车。
- `DP_LINCOLN_AUTO_LC_POST_FINISH_COOLDOWN_SEC = 1.0`：变道完成后短时间内不再启动自动变道。

## 7. 语音提示（`selfdrive/ui/soundd.py`）
### 7.1 避让提示音
- 文件：`alert_chime.wav`
- 条件：
  - `dp_lincoln_auto_avoid == True`
  - `bsm_available == True`
  - 未打灯，且 `v_ego >= 10 mph`
  - `obstacle_in_path = inPath or vehicleInPath` 从 False→True 上升沿
- 限制：`AUTO_AVOID_CHIME_MIN_INTERVAL_S = 2.0`

### 7.2 Hazard 提示音
- 文件：`warning_immediate.wav`
- 条件：
  - `hazInPath` 从 False→True 上升沿
  - 未打灯，且 `v_ego >= 10 mph`
  - **不依赖** `dp_lincoln_auto_avoid`（内部强制开启）
- 限制：`HAZARD_CHIME_MIN_INTERVAL_S = 2.0`

### 7.3 数据过期清零
- `AUTO_AVOID_CHIME_STALE_TIMEOUT_S = 1.0` → 超过 1s 未更新检测即清零。

## 8. 复刻步骤
1. 注册参数键（auto_avoid + cone detection）。
2. 面板添加 Auto avoidance 与 Cone Detection 开关。
3. coned 输出 customReservedRawData0（JSON）。
4. longitudinal_planner 实现减速/停车逻辑。
5. auto_avoidance.py 实现状态机。
6. modeld 接入避让方向与安全门槛。
7. soundd 增加提示音逻辑。

## 9. 验证清单
- 开启 auto_avoid 后，inPath 触发时巡航被限制。
- 行人进入本车道时停车而非变道。
- 车道不可用（BSM/路沿/目标车道阻塞）时不自动变道。
- 障碍消失 2s 后自动返回原车道。
