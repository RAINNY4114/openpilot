# 林肯面板：性能信息显示（dp_lincoln_perf_info_enabled）复刻文档
## 0. 功能定义
- 在 HUD 底部显示性能与道路信息条：
  - Curvature / Direction / Road / Control / Memory / CPU Temp
- 仅 UI 绘制，不影响控制逻辑。

## 1. 参数与开关（`common/params_keys.h`）
- `dp_lincoln_perf_info_enabled`：PERSISTENT BOOL，默认 `0`。
- `RoadName`：CLEAR_ON_MANAGER_START STRING（`mapd` 写入，默认空字符串）。
- `GPSQualityOK`：CLEAR_ON_MANAGER_START BOOL（`mapd` 写入，默认 `0`）。

## 2. 面板设置入口（UI）
- 文件：`selfdrive/ui/layouts/settings/lincoln.py`
- Toggle 文案：
  - 标题：`Show performance info`
  - 描述：`Display device performance information at the bottom: CPU temperature, memory usage, CPU usage, and FPS. Requires UI restart.`
- 注意：描述文本提到 CPU usage/FPS，但**实际不显示**，需保持该差异以 1:1 复刻。

## 3. UI 状态缓存
- 文件：`selfdrive/ui/ui_state.py`
- 缓存字段：`ui_state.dp_lincoln_perf_info_enabled`
- 刷新频率：每 1s 更新一次。

## 4. 关键常量（`selfdrive/ui/onroad/augmented_road_view.py`）
- `PERF_DIRECTION_LABELS = ("N","NE","E","SE","S","SW","W","NW")`
- `PERF_FONT_SIZE = 32`
- `PERF_PADDING = 12`
- `PERF_MARGIN_BOTTOM = UI_BORDER_SIZE // 2`
- `PERF_ITEM_GAP = 140`
- `PERF_BG_COLOR = rl.Color(0, 0, 0, 120)`

## 5. 运行时数据来源（消息与文件）
- 曲率/方向/控制状态：
  - `controlsState.curvature`（绝对值，3 位小数）
  - `carState.steeringAngleDeg`（1 位小数，带°）
  - `carState.steeringTorque`（1 位小数，带 Nm）
- 方向（优先级）：
  1) `gpsLocationExternal` / `gpsLocation` 的 `bearingDeg`
  2) 同一消息的 `vN/vE` 向量
  3) `livePose.velocityDevice` 计算航向
  4) 若均无效 → `---`
- 道路名：`RoadName`（mapd 输出）
- GPS 质量：`GPSQualityOK`（mapd 输出）
- 设备状态：
  - CPU 温度：`/sys/class/thermal/thermal_zone0/temp`
  - 内存使用率：`/proc/meminfo`（MemTotal / MemAvailable）
  - 磁盘剩余：`/data`（`shutil.disk_usage`）
  - 注意：磁盘剩余目前只计算并缓存，但 **不显示**。

## 6. UI 渲染逻辑（完全 1:1）
### 6.1 文字内容与顺序
- `base_items` 固定顺序：
  1) `Curvature {curvature}/{steering}/{torque}`
  2) `Direction {direction}`
  3) `Road {road}`
  4) `Control {control}`
  5) `Memory {mem_usage}`
  6) `CPU Temp {cpu_temp}`

### 6.2 布局与宽度控制
- 最大宽度：`max_width = min(rect.width - 40, rect.width * 0.98)`。
- 目标宽度：`total_text_width + 2*PERF_PADDING + gap*(items-1)`。
- gap 初始为 `PERF_ITEM_GAP`，会根据剩余宽度缩小。
- 过长时只压缩 **Road 值**：
  - 计算可用宽度 = 总宽度 - 其它文本 - gap - Road 标签宽度。
  - 用 `_ellipsize_text_to_width()` 二分截断，后缀 `...`。
- 若 `bar_y < rect.y + PERF_MARGIN_BOTTOM`，则向上夹到最小位置，避免遮挡顶部区域。

### 6.3 字体与中文兼容
- 默认字体：`font_fallback(self._perf_font)`。
- Road 文本若缺字：
  - 使用 `_font_has_missing_glyphs()` 检测。
  - 动态加载 `unifont.otf` 子集（`_get_dynamic_unifont_font()`）。
  - 字体缓存最多 8 组，超过即 LRU 清理。
  - `unifont` 加载大小 64，贴图过滤 `BILINEAR`。
- 绘制时对 Road 单独使用动态字体，其它字段仍用默认字体。

### 6.4 绘制区域与裁剪
- 条形背景：圆角矩形，背景色 `PERF_BG_COLOR`。
- 使用 `begin_scissor_mode` 将文字裁剪在条形区域内，防止覆盖其它 HUD。

## 7. RoadName / GPS 回退逻辑
- 位置缓存：`_road_loc_cache` 在 0.5s 内直接返回，避免频繁测量/字体计算。
- RoadName 读取逻辑：
  - 读取顺序：优先 `/dev/shm/params`（params_memory），其次持久 Params。
  - 从 `Params` 获取 `RoadName`，空字符串则视为无效。
  - 归一化：`" ".join(road_name.split())` 清理多空格。
  - 超长保护：`len > 120` 截断到 117 + `...`。
- GPS 质量过滤：
  - 若 `GPSQualityOK == False` 且已有 `road_name_last`，则拒绝新路名，保持旧值。
- 去抖与稳定：
  - 新路名变化后要稳定 1s 才真正切换。
  - 使用 `_road_name_candidate` 缓存候选值。
- 无 RoadName 时的保持策略：
  - 默认保持 30s；
  - 静止（`standstill`）保持 3600s；
  - `vEgo < 1.0` 时保持 60s。
- 最终回退到 GPS 坐标：
  - `gpsLocationExternal` 或 `gpsLocation`（要求 `hasFix`）。
  - 显示 `lat,lon`（小数 5 位）。
  - GPS 短暂失效时保留最后坐标，防止 `--` 闪烁。

## 8. 方向（Direction）计算
- 先用 `bearingDeg`；若无效，使用 `vN/vE` 计算 `atan2`。
- 方向标签映射至 `PERF_DIRECTION_LABELS`，并通过 `tr()` 翻译。
- 若 GPS 信息无效，则使用 `livePose.velocityDevice` 作为回退（需 `valid==True` 且 `abs(vn)+abs(ve) > 0.1`）。

## 9. 性能数据采集线程
- 位置：`AugmentedRoadView.__init__` 启动 `_perf_thread`。
- 初始延迟：5 秒。
- 频率：约 1 秒更新一次。
- `stats` 字段：`cpu_temp`、`mem_usage`、`disk_free`。

## 11. 复刻步骤（一步不省）
1. 注册参数：`dp_lincoln_perf_info_enabled`、`RoadName`、`GPSQualityOK`。
2. UI 添加 `Show performance info` 开关（文案保持一致）。
3. `ui_state` 读取并缓存开关值。
4. 在 `AugmentedRoadView` 中实现：
   - `_draw_performance_info()` 绘制条形信息；
   - `_get_road_location_text()` 完整 RoadName/GPS 回退逻辑；
   - `_get_direction_label()` 方向计算与回退；
   - 动态字体加载与 LRU 缓存；
   - 性能采集线程 `_perf_update_loop()`。

## 12. 验证清单
- 开关打开后底部出现性能条，内容顺序固定。
- RoadName 为中文时不出现乱码（动态 `unifont` 正常工作）。
- GPS 抖动时 RoadName 不频繁跳变，坐标回退稳定。
- 控制状态随 ENGAGED/非 ENGAGED 正确切换 `Auto control/Manual control`。
