## 林肯面板「显示性能信息」功能实现

> 目标：在其它分支中 1:1 复刻该功能。以下按照文件路径列出所有涉及的代码与逻辑，按顺序逐项移植即可。

---

### 1. 参数声明

- **文件**：`common/params_keys.h`
- **新增键**：
  ```cpp
  {"dp_lincoln_perf_info_enabled", {PERSISTENT, BOOL, "0"}},
  ```
  控制 HUD 是否绘制性能信息，默认关闭。

---

### 2. Lincoln 设置面板开关

- **文件**：`selfdrive/ui/layouts/settings/lincoln.py`
- **位置**：HUD & Visualization 区块
  ```python
  toggle_item(
    title=lambda: tr("Show performance info"),
    description=lambda: tr("Display device performance information at the bottom: CPU temperature, memory usage, CPU usage, and FPS. Requires UI restart."),
    initial_state=self._params.get_bool("dp_lincoln_perf_info_enabled"),
    callback=lambda val: self._params.put_bool("dp_lincoln_perf_info_enabled", val),
  ),
  ```
  用户开关与 Params 绑定，无需额外逻辑。

---

### 3. UI 状态同步

- **文件**：`selfdrive/ui/ui_state.py`
- **初始化**：
  ```python
  self.dp_lincoln_perf_info_enabled = False
  ```
- **每帧更新**（`_update_settings_params`）：
  ```python
  self.dp_lincoln_perf_info_enabled = self.params.get_bool("dp_lincoln_perf_info_enabled")
  ```
  这样 onroad HUD 能即时响应面板开关。

---

### 4. Augmented Road View 渲染

**文件**：`selfdrive/ui/onroad/augmented_road_view.py`

#### 4.1 性能数据缓存

```python
self._perf_stats = {"cpu_temp": "N/A", "mem_usage": "N/A", "disk_free": "N/A"}
self._perf_thread = threading.Thread(target=self._perf_update_loop, daemon=True)
self._perf_thread.start()
```

#### 4.2 后台采集 `_perf_update_loop`

```python
time.sleep(10)
while self._perf_running:
  # CPU 温度
  with open("/sys/class/thermal/thermal_zone0/temp") as f:
    temp_c = int(f.read().strip()) / 1000.0
    self._perf_stats["cpu_temp"] = f"{temp_c:.0f}°C"
  # 内存占用
  with open("/proc/meminfo") as f:
    ...
    self._perf_stats["mem_usage"] = f"{mem_used_pct:.0f}%"
  # /data 剩余磁盘
  stat = shutil.disk_usage('/data')
  ...
  self._perf_stats["disk_free"] = f"{free_gb:.1f}GB" or `MB`
  time.sleep(1.0)
```
所有异常写入 `"N/A"`/`"ERR"`，避免阻塞渲染。

#### 4.3 曲率图留白

在 `_draw_curvature_time_series()` 中：

```python
perf_info_height = 50 if ui_state.dp_lincoln_perf_info_enabled else 0
top = content_rect.y + content_rect.height - margin_bottom - plot_height - perf_info_height
```

开启性能条时为底部预留 50px，防止重叠。

#### 4.4 HUD 绘制入口

`_render()` 末尾依次调用：

```python
self._draw_curvature_time_series(...)
self._draw_performance_info(...)
if ui_state.dp_lincoln_confidence_bar_enabled:
  self._draw_confidence_indicator(...)
```

#### 4.5 `_draw_performance_info()`

```python
if not ui_state.dp_lincoln_perf_info_enabled:
  return

font_size = 32
bg_padding = 8
bg_color = rl.Color(0, 0, 0, 80)
text_color = rl.WHITE

cpu_temp = self._perf_stats["cpu_temp"]
mem_usage = self._perf_stats["mem_usage"]
# 控制状态（engaged=自动接管，否则人工接管）
control = tr("Auto control") if ui_state.status == UIStatus.ENGAGED else tr("Manual control")
# 曲率 + 方向盘角度
curvature = f"{abs(kappa):.3f}" 或 fallback
steering_angle = f"{sa_deg:.1f}°"

# GPS 方向（N/NE/...）
direction = tr("N") 等

items = [
  f"{tr('Curvature')} {curvature}/{steering_angle}",
  f"{tr('Direction')} {direction}",
  f"{tr('Control')} {control}",
  f"{tr('Memory')} {mem_usage}",
  f"{tr('CPU Temp')} {cpu_temp}",
]

# 根据文字宽度居中摆放，每项间隔 140px，绘制统一半透明背景
```

##### 方向获取（修复点）
- 优先使用 `gpsLocationExternal.bearingDeg`，若无效则用 `gpsLocationExternal` 的 `vN/vE` 估算方位；外部 GPS 不可用时回退到 `gpsLocation` 同样逻辑，再回退到 `livePose.velocityDevice`。仅在完全无效时显示 `---`。
- 对应逻辑：`AugmentedRoadView._get_direction_label()`。
- UI 订阅：`ui_state` 需订阅 `gpsLocationExternal`、`gpsLocation`、`livePose`，确保方向来源存在；如需复刻请同步 SubMaster 列表。

---

### 6. 行为摘要

- 开关位于 Lincoln 面板 HUD 部分，写入 Params。
- `ui_state` 每帧读取开关，`augmented_road_view` 根据布尔值决定是否绘制/预留空间。
- 性能数据由后台线程每秒刷新，渲染线程只读缓存，CPU/GPU 负担极低。
- HUD 底部中央一次性显示 4 个字段，背景为 80 alpha 的黑色矩形，字体 32px，文字间距 140px。
- 曲率时序图在性能条上方自动避让，信心条仍位于底部，三者不会互相遮挡。

照上述步骤复制全部片段，即可在其它分支 1:1 还原“显示性能信息”功能。
